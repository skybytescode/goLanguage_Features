# Structs și metode — Practician

Go preferă **compoziția** în locul moștenirii. Instrumentul principal e *embedding*-ul. Tot aici intră constructorii, valorile zero utile, tag-urile și regulile despre ce metode poate apela o valoare.

## Embedding: compoziție, nu moștenire

Un câmp fără nume (doar tipul) e un câmp **încorporat**. Câmpurile și metodele lui sunt **promovate**: le poți folosi direct pe structura exterioară.

```go
package main

import "fmt"

type Adresa struct {
	Oras, Strada string
}

func (a Adresa) Complet() string { return a.Strada + ", " + a.Oras }

type Client struct {
	Nume   string
	Adresa // încorporat
}

func main() {
	c := Client{Nume: "Ana", Adresa: Adresa{Oras: "Cluj", Strada: "Memorandumului 1"}}
	fmt.Println(c.Oras)      // promovat: c.Adresa.Oras
	fmt.Println(c.Complet()) // metodă promovată
}
```

Diferența față de moștenire: receptorul metodei promovate rămâne **câmpul interior**. `Adresa.Complet` nu știe nimic despre `Client`, și nu există „metode virtuale” suprascrise.

```go
package main

import "fmt"

type Animal struct{}

func (Animal) Sunet() string      { return "..." }
func (a Animal) Vorbeste() string { return "spune " + a.Sunet() }

type Caine struct{ Animal }

func (Caine) Sunet() string { return "ham" }

func main() {
	c := Caine{}
	fmt.Println(c.Sunet())    // ham: metoda lui Caine o ascunde pe cea promovată
	fmt.Println(c.Vorbeste()) // spune ...: Animal.Vorbeste apelează Animal.Sunet
}
```

Dacă ai nevoie de comportament polimorfic, folosește o **interfață**, nu embedding.

## Constructori

Go nu are constructori speciali. Convenția e o funcție `NewT` care întoarce o valoare validă (de obicei `*T`) și, dacă e nevoie, o eroare:

```go
package main

import (
	"errors"
	"fmt"
)

type Interval struct {
	min, max int
}

func NewInterval(min, max int) (*Interval, error) {
	if min > max {
		return nil, errors.New("min > max")
	}
	return &Interval{min: min, max: max}, nil
}

func (i *Interval) Contine(x int) bool { return x >= i.min && x <= i.max }

func main() {
	i, err := NewInterval(1, 10)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(i.Contine(5), i.Contine(11))
}
```

## Fă valoarea zero utilă

Multe tipuri din biblioteca standard funcționează direct, fără constructor: `bytes.Buffer`, `strings.Builder`, `sync.Mutex`, `sync.WaitGroup`. Proiectează la fel când poți: un câmp `nil` poate fi inițializat leneș.

```go
package main

import "fmt"

type Contoare struct {
	m map[string]int
}

func (c *Contoare) Inc(cheie string) {
	if c.m == nil {
		c.m = make(map[string]int) // inițializare leneșă
	}
	c.m[cheie]++
}

func main() {
	var c Contoare // fără constructor
	c.Inc("a")
	c.Inc("a")
	fmt.Println(c.m["a"]) // 2
}
```

## Method sets: ce metode are o valoare

- Tipul `T` are în method set doar metodele cu receptor **valoare**.
- Tipul `*T` are metodele cu receptor valoare **și** pe cele cu receptor pointer.

Când apelezi `v.M()` pe o variabilă, Go ia automat adresa (`(&v).M()`) dacă e nevoie. Asta merge doar pentru valori **adresabile**. Elementele unui map și valorile întoarse de funcții nu sunt adresabile:

```go,compile_fail
package main

type Contor struct{ n int }

func (c *Contor) Inc() { c.n++ }

func main() {
	m := map[string]Contor{"a": {}}
	m["a"].Inc() // eroare: cannot call pointer method Inc on Contor
}
```

Regula contează mai ales la interfețe: dacă metodele sunt pe `*T`, doar `*T` implementează interfața, nu și `T`. Vezi [Interfețe](../../interfete/2/).

## Nu copia structurile care conțin un mutex

Copierea unei structuri copiază și mutex-ul, cu tot cu starea lui. `go vet` (analizorul `copylocks`) prinde cazurile acestea:

```go,ignore
type Cache struct {
	mu   sync.Mutex
	date map[string]string
}

func (c Cache) Get(k string) string { // vet: Get passes lock by value
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.date[k]
}
```

Soluția: receptor pointer (`func (c *Cache) Get`).

## Tag-uri

Câmpurile pot avea **tag-uri**: string-uri citite prin reflection de pachete precum `encoding/json`:

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Produs struct {
	ID     int     `json:"id"`
	Nume   string  `json:"nume"`
	Pret   float64 `json:"pret,omitempty"`
	intern string  // neexportat: ignorat de json
}

func main() {
	b, _ := json.Marshal(Produs{ID: 1, Nume: "carte", intern: "x"})
	fmt.Println(string(b)) // {"id":1,"nume":"carte"}
}
```

## Structura goală

`struct{}` ocupă **zero** octeți. Se folosește ca valoare în seturi (`map[string]struct{}`) și ca semnal pe channels (`chan struct{}`).

## Pe scurt

- Embedding promovează câmpuri și metode, dar nu e moștenire.
- `NewT` pentru validare; altfel, fă valoarea zero utilizabilă.
- `T` are doar metodele cu receptor valoare; `*T` le are pe toate.
- Nu copia structuri cu mutex; `go vet` te ajută.
- Tag-urile controlează serializarea.
