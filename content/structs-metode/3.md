# Structs și metode — Avansat

Regulile exacte de selecție a câmpurilor promovate, încorporarea interfețelor, metodele ca funcții obișnuite, structurile ca chei de map și câteva tehnici de design al structurilor folosite chiar în biblioteca standard.

## Regula adâncimii pentru selectori

La `x.f`, Go caută `f` la **adâncimea cea mai mică**: întâi câmpurile și metodele lui `x`, apoi cele ale câmpurilor încorporate direct, apoi un nivel mai jos și tot așa. Dacă la cea mai mică adâncime există **două** potriviri, selectorul e ambiguu, dar eroarea apare doar dacă îl folosești:

```go,compile_fail
package main

type A struct{}

func (A) Nume() string { return "A" }

type B struct{}

func (B) Nume() string { return "B" }

type C struct {
	A
	B
}

func main() {
	var c C
	_ = c // C compilează fără probleme...
	println(c.Nume()) // ...dar aici: ambiguous selector c.Nume
}
```

Rezolvarea e explicită: `c.A.Nume()`, sau o metodă `Nume` definită pe `C`, care le ascunde pe amândouă.

## Încorporarea unei interfețe într-o structură

O structură poate încorpora o **interfață**. Structura implementează atunci interfața, iar tu suprascrii doar metodele care te interesează. Exact așa e făcut `sort.Reverse`:

```go
package main

import (
	"fmt"
	"sort"
)

type invers struct {
	sort.Interface // Len și Swap sunt delegate
}

func (r invers) Less(i, j int) bool { return r.Interface.Less(j, i) }

func main() {
	s := []int{3, 1, 2}
	sort.Sort(invers{sort.IntSlice(s)})
	fmt.Println(s) // [3 2 1]
}
```

Atenție: dacă interfața încorporată e `nil`, orice metodă nesuprascrisă dă panic la apel. Tehnica e utilă și în teste, pentru mock-uri parțiale.

## Metodele sunt funcții

O metodă e o funcție al cărei prim parametru e receptorul. Method expression-ul face asta vizibil, și permite tabele de operații fără interfețe:

```go
package main

import "fmt"

type Vector struct{ X, Y float64 }

func (v Vector) Plus(w Vector) Vector  { return Vector{v.X + w.X, v.Y + w.Y} }
func (v Vector) Minus(w Vector) Vector { return Vector{v.X - w.X, v.Y - w.Y} }

func main() {
	ops := map[string]func(Vector, Vector) Vector{
		"+": Vector.Plus,
		"-": Vector.Minus,
	}
	a, b := Vector{1, 2}, Vector{3, 4}
	fmt.Println(ops["+"](a, b), ops["-"](a, b))
}
```

## Structuri comparabile ca chei de map

O structură cu toate câmpurile comparabile poate fi cheie de map. Hash-ul se calculează pe toate câmpurile. E un înlocuitor eficient pentru chei compuse construite cu `fmt.Sprintf`:

```go
package main

import "fmt"

type cheie struct {
	oras string
	an   int
}

func main() {
	populatie := map[cheie]int{
		{"Cluj", 2021}: 286598,
		{"Iași", 2021}: 271692,
	}
	fmt.Println(populatie[cheie{"Cluj", 2021}])
}
```

O structură care conține un slice, map sau funcție **nu** e comparabilă și nu poate fi cheie.

## Tehnici din biblioteca standard

**Forțarea inițializării cu nume.** Un câmp `_` gol împiedică literalele poziționale în alte pachete:

```go,ignore
type Optiuni struct {
	_       struct{} // Optiuni{1, 2} nu mai compilează: trebuie Optiuni{A: 1, B: 2}
	A, B    int
}
```

**Interzicerea comparării.** Un câmp de tip array de funcții, de dimensiune zero, face structura necomparabilă fără să ocupe memorie:

```go,ignore
type Token struct {
	_ [0]func() // Token == Token nu mai compilează
	valoare string
}
```

**Marcaj „nu copia”.** Un tip `noCopy` cu metodele `Lock` și `Unlock` face ca `go vet` să semnaleze copierea structurii, fără costuri la rulare. Așa sunt protejate `sync.WaitGroup` și `strings.Builder`.

**Câmpul de dimensiune zero la final.** Dacă ultimul câmp are dimensiune zero (`struct{}`, `[0]int`), compilatorul adaugă padding ca un pointer la el să nu indice în obiectul următor din memorie. Pune astfel de câmpuri la început.

**`structs.HostLayout` (Go 1.23).** Compilatorul are libertatea, teoretic, să reordoneze câmpurile. Un câmp `_ structs.HostLayout` cere layout-ul platformei, necesar când structura e transmisă către C sau către sistemul de operare.

## Pe scurt

- Selectorii caută la adâncimea minimă; ambiguitatea e eroare doar la folosire.
- Încorporarea unei interfețe dă implementări parțiale (vezi `sort.Reverse`).
- Metodele sunt funcții cu receptorul ca prim parametru.
- Structurile comparabile sunt chei de map excelente.
- `_ struct{}`, `_ [0]func()` și `noCopy` controlează cum poate fi folosit un tip.
