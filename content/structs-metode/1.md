# Structs și metode — Fundamente

Go nu are clase. În locul lor folosești **structuri** (`struct`) pentru date și **metode** atașate tipurilor pentru comportament.

## Definirea unei structuri

O structură grupează câmpuri cu nume:

```go
package main

import "fmt"

type Carte struct {
	Titlu  string
	Autor  string
	Pagini int
}

func main() {
	c := Carte{Titlu: "Ion", Autor: "Liviu Rebreanu", Pagini: 480}
	fmt.Println(c.Titlu, "de", c.Autor)

	c.Pagini = 500 // câmpurile se modifică direct
	fmt.Printf("%+v\n", c)
}
```

## Moduri de a crea o structură

```go
package main

import "fmt"

type Punct struct {
	X, Y int
}

func main() {
	a := Punct{1, 2}        // pozițional: fragil dacă se schimbă ordinea câmpurilor
	b := Punct{X: 3}        // cu nume: câmpurile lipsă primesc valoarea zero (Y = 0)
	var c Punct             // valoarea zero: {0 0}
	d := &Punct{X: 5, Y: 6} // pointer la o structură nouă

	fmt.Println(a, b, c, *d)
}
```

Preferă mereu forma **cu nume** a câmpurilor: rămâne corectă și când adaugi câmpuri noi.

## Metode

O metodă e o funcție cu un **receptor** (receiver), scris între `func` și numele metodei:

```go
package main

import (
	"fmt"
	"math"
)

type Cerc struct {
	Raza float64
}

func (c Cerc) Arie() float64 {
	return math.Pi * c.Raza * c.Raza
}

func (c Cerc) Perimetru() float64 {
	return 2 * math.Pi * c.Raza
}

func main() {
	c := Cerc{Raza: 2}
	fmt.Printf("arie %.2f, perimetru %.2f\n", c.Arie(), c.Perimetru())
}
```

## Receptor valoare vs. receptor pointer

Cu un receptor **valoare** (`c Cerc`), metoda lucrează pe o copie. Ca să modifice structura, metoda are nevoie de un receptor **pointer** (`c *Cerc`):

```go
package main

import "fmt"

type Cont struct {
	Sold int
}

func (c Cont) Afiseaza() {
	fmt.Println("sold:", c.Sold)
}

func (c *Cont) Depune(suma int) {
	c.Sold += suma
}

func main() {
	cont := Cont{}
	cont.Depune(100) // Go ia automat &cont
	cont.Depune(50)
	cont.Afiseaza() // sold: 150
}
```

Regula practică: dacă **o** metodă a tipului are nevoie de receptor pointer, folosește receptor pointer la **toate**, pentru consecvență.

## Metode pe orice tip definit

Metodele nu sunt doar pentru structuri. Orice tip definit în pachetul tău poate avea metode:

```go
package main

import (
	"fmt"
	"strings"
)

type Cuvinte []string

func (c Cuvinte) Uneste() string {
	return strings.Join(c, " ")
}

func main() {
	c := Cuvinte{"Go", "e", "simplu"}
	fmt.Println(c.Uneste())
}
```

## Câmpuri exportate și neexportate

Un nume care începe cu **literă mare** e vizibil din alte pachete (exportat). Cu literă mică, e vizibil doar în pachetul curent. Regula se aplică la tipuri, câmpuri, funcții și metode deopotrivă.

```go,ignore
type Utilizator struct {
	Nume   string // exportat
	parola string // privat pachetului
}
```

## Structuri anonime

Pentru date folosite o singură dată (de exemplu în teste), poți declara structura direct:

```go
package main

import "fmt"

func main() {
	teste := []struct {
		intrare  int
		asteptat int
	}{
		{1, 2},
		{5, 10},
	}
	for _, t := range teste {
		fmt.Println(t.intrare*2 == t.asteptat)
	}
}
```

## Comparația structurilor

Două structuri se pot compara cu `==` dacă toate câmpurile sunt comparabile. Sunt egale dacă toate câmpurile sunt egale:

```go
package main

import "fmt"

type Punct struct{ X, Y int }

func main() {
	fmt.Println(Punct{1, 2} == Punct{1, 2}) // true
}
```

## Pe scurt

- `struct` grupează date; metodele adaugă comportament.
- Folosește câmpuri cu nume la inițializare.
- Receptor pointer pentru metodele care modifică; consecvent pe tot tipul.
- Literă mare = exportat, literă mică = privat pachetului.
