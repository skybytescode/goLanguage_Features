# Reflection și unsafe — Fundamente

**Reflection** înseamnă că un program își poate inspecta propriile tipuri și valori la rulare: ce tip are o variabilă, ce câmpuri are o structură, ce tag-uri au acestea. Pachetul `reflect` face asta posibil. E puternic, dar îl vei folosi rar direct; îl folosesc însă, în spate, `fmt`, `encoding/json` și multe alte biblioteci.

## Tipul unei valori

```go
package main

import (
	"fmt"
	"reflect"
)

type Punct struct{ X, Y int }

func main() {
	valori := []any{42, "salut", 3.14, []int{1, 2}, Punct{1, 2}, &Punct{}}
	for _, v := range valori {
		t := reflect.TypeOf(v)
		fmt.Printf("%-12v kind=%v\n", t, t.Kind())
	}
}
```

- **`Type`** e tipul exact (`main.Punct`, `[]int`).
- **`Kind`** e categoria de bază: `Int`, `String`, `Slice`, `Struct`, `Ptr` etc. Mai multe tipuri diferite pot avea același `Kind`.

`fmt.Printf("%T", v)` folosește exact acest mecanism.

## Valoarea: `reflect.ValueOf`

`reflect.Value` permite citirea valorii, indiferent de tip:

```go
package main

import (
	"fmt"
	"reflect"
)

func descrie(x any) {
	v := reflect.ValueOf(x)
	switch v.Kind() {
	case reflect.Int, reflect.Int64:
		fmt.Println("întreg:", v.Int())
	case reflect.String:
		fmt.Println("text de lungime", v.Len())
	case reflect.Slice:
		fmt.Println("slice cu", v.Len(), "elemente")
	default:
		fmt.Println("alt tip:", v.Kind())
	}
}

func main() {
	descrie(7)
	descrie("Go")
	descrie([]string{"a", "b", "c"})
	descrie(true)
}
```

Pentru cazuri ca acesta, un **type switch** (vezi [Interfețe](../../interfete/1/)) e de obicei mai simplu. Reflection devine necesar când nu știi tipurile dinainte: de exemplu, orice structură definită de utilizator.

## Câmpurile unei structuri și tag-urile

Așa citesc pachetele ca `encoding/json` tag-urile:

```go
package main

import (
	"fmt"
	"reflect"
)

type Utilizator struct {
	Nume   string `json:"nume" validate:"required"`
	Email  string `json:"email"`
	Varsta int    `json:"varsta,omitempty"`
}

func main() {
	t := reflect.TypeFor[Utilizator]() // Go 1.22; echivalent cu reflect.TypeOf(Utilizator{})
	for i := 0; i < t.NumField(); i++ {
		camp := t.Field(i)
		fmt.Printf("%-7s %-7v json=%q validate=%q\n",
			camp.Name, camp.Type, camp.Tag.Get("json"), camp.Tag.Get("validate"))
	}
}
```

## Când să folosești reflection

Rar. Reflection:

- e **mai lent** decât codul obișnuit (de zeci de ori, în multe cazuri);
- mută erorile de la compilare la **rulare** (un panic în loc de o eroare de compilator);
- face codul mai greu de citit.

Folosește-l pentru biblioteci generale (serializare, validare, ORM-uri, injectare de dependențe). Pentru restul, interfețele și generics sunt mai bune.

## Ce e `unsafe`

Pachetul `unsafe` permite operații pe care sistemul de tipuri al Go le interzice: citirea memoriei ca alt tip, aritmetică pe pointeri. Numele spune tot: codul care îl folosește poate corupe memoria și nu mai beneficiază de garanțiile de compatibilitate ale Go.

Partea inofensivă și utilă pentru învățare: funcțiile care spun cât ocupă un tip în memorie.

```go
package main

import (
	"fmt"
	"unsafe"
)

type Exemplu struct {
	A bool
	B int64
	C bool
}

func main() {
	fmt.Println(unsafe.Sizeof(int32(0)))      // 4
	fmt.Println(unsafe.Sizeof(""))            // 16: pointer + lungime
	fmt.Println(unsafe.Sizeof([]int{}))       // 24: pointer + len + cap
	fmt.Println(unsafe.Sizeof(Exemplu{}))     // 24: include padding
	fmt.Println(unsafe.Offsetof(Exemplu{}.B)) // 8: B începe după 7 octeți de padding
}
```

Valorile sunt pentru o platformă de 64 de biți.

## Pe scurt

- `reflect.TypeOf` dă tipul, `reflect.ValueOf` valoarea; `Kind` e categoria.
- Câmpurile și tag-urile structurilor se citesc cu `Type.Field(i)`.
- Reflection e lent și mută erorile la rulare: folosește-l doar în biblioteci generale.
- `unsafe` ocolește sistemul de tipuri; `Sizeof` și `Offsetof` sunt utile pentru înțelegerea memoriei.
