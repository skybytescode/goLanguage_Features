# Functions and closures — Fundamentals

Functions are the basic building blocks of a Go program. They can take several parameters, return several values and be stored in variables like any other value.

## Declaring a function

```go
package main

import "fmt"

func add(a int, b int) int {
	return a + b
}

// consecutive parameters of the same type can share it
func multiply(a, b int) int {
	return a * b
}

func main() {
	fmt.Println(add(2, 3))      // 5
	fmt.Println(multiply(4, 5)) // 20
}
```

The type comes **after** the name, for both parameters and the result.

## Multiple return values

A function can return several values. Most often, the last one is an error:

```go
package main

import (
	"errors"
	"fmt"
)

func divide(a, b float64) (float64, error) {
	if b == 0 {
		return 0, errors.New("division by zero")
	}
	return a / b, nil
}

func main() {
	res, err := divide(10, 4)
	if err != nil {
		fmt.Println("error:", err)
		return
	}
	fmt.Println(res) // 2.5

	_, err = divide(1, 0) // ignore the result with _
	fmt.Println(err)
}
```

## Named results

Results can have names. They are ordinary variables, initialized to their zero value; a bare `return` returns them:

```go
package main

import "fmt"

func minMax(numbers []int) (lo, hi int) {
	lo, hi = numbers[0], numbers[0]
	for _, n := range numbers {
		if n < lo {
			lo = n
		}
		if n > hi {
			hi = n
		}
	}
	return // returns lo and hi
}

func main() {
	fmt.Println(minMax([]int{3, 9, 1, 7})) // 1 9
}
```

Names help documentation. A bare `return` only suits short functions; in long ones it makes the code hard to follow.

## Variadic functions

The last parameter can accept any number of values, with `...`. Inside the function it's a slice:

```go
package main

import "fmt"

func sum(numbers ...int) int {
	total := 0
	for _, n := range numbers {
		total += n
	}
	return total
}

func main() {
	fmt.Println(sum())        // 0
	fmt.Println(sum(1, 2, 3)) // 6

	values := []int{10, 20}
	fmt.Println(sum(values...)) // an existing slice, "unpacked"
}
```

`fmt.Println` is variadic too: `func Println(a ...any)`.

## Functions are values

You can store a function in a variable, pass it as a parameter or return it:

```go
package main

import "fmt"

func apply(numbers []int, f func(int) int) []int {
	res := make([]int, 0, len(numbers))
	for _, n := range numbers {
		res = append(res, f(n))
	}
	return res
}

func double(x int) int { return x * 2 }

func main() {
	fmt.Println(apply([]int{1, 2, 3}, double)) // [2 4 6]

	// an anonymous function, written right at the call
	fmt.Println(apply([]int{1, 2, 3}, func(x int) int { return x * x })) // [1 4 9]
}
```

## Closures

An anonymous function can use variables from the function it was created in. We say it **captures** them: it keeps them alive even after the outer function has returned.

```go
package main

import "fmt"

func counter() func() int {
	n := 0
	return func() int {
		n++ // modifies the captured variable
		return n
	}
}

func main() {
	next := counter()
	fmt.Println(next(), next(), next()) // 1 2 3

	other := counter()   // a different closure, with its own n
	fmt.Println(other()) // 1
}
```

## Summary

- `func name(param type) resultType { ... }`; types come after names.
- A function can return several values; the error is usually last.
- `...T` makes a function variadic; `slice...` passes an existing slice.
- Functions are values: they can be parameters, results or variables.
- Closures capture the surrounding variables, not copies of them.
