# Functions and closures — Practitioner

Functions as values enable several patterns that are everywhere in Go: function types that implement interfaces, middleware, "functional options" and method values.

## Function types

You can define a type from a signature and add methods to it. This is how `http.HandlerFunc` works: an ordinary function becomes an `http.Handler`.

```go
package main

import "fmt"

type Validator interface {
	Valid(s string) bool
}

// ValidatorFunc adapts a function to the Validator interface.
type ValidatorFunc func(string) bool

func (f ValidatorFunc) Valid(s string) bool { return f(s) }

func check(v Validator, values ...string) {
	for _, s := range values {
		fmt.Printf("%q: %t\n", s, v.Valid(s))
	}
}

func main() {
	nonEmpty := ValidatorFunc(func(s string) bool { return s != "" })
	check(nonEmpty, "abc", "")
}
```

## Middleware: functions wrapping functions

A function that takes a function and returns another of the same type can add behavior (logging, timing, retries) without touching the original code:

```go
package main

import (
	"fmt"
	"strings"
)

type Transform func(string) string

func withLog(name string, f Transform) Transform {
	return func(s string) string {
		res := f(s)
		fmt.Printf("%s(%q) = %q\n", name, s, res)
		return res
	}
}

func chain(fs ...Transform) Transform {
	return func(s string) string {
		for _, f := range fs {
			s = f(s)
		}
		return s
	}
}

func main() {
	t := chain(
		withLog("trim", strings.TrimSpace),
		withLog("upper", strings.ToUpper),
	)
	fmt.Println(t("  hello  "))
}
```

`strings.TrimSpace` has exactly the type `func(string) string`, so it fits `Transform` directly.

## Functional options

For constructors with many optional settings, Go often uses the **functional options** pattern: each option is a function that modifies the configuration.

```go
package main

import (
	"fmt"
	"time"
)

type Server struct {
	addr     string
	timeout  time.Duration
	maxConns int
}

type Option func(*Server)

func WithTimeout(d time.Duration) Option {
	return func(s *Server) { s.timeout = d }
}

func WithMaxConns(n int) Option {
	return func(s *Server) { s.maxConns = n }
}

func NewServer(addr string, opts ...Option) *Server {
	s := &Server{addr: addr, timeout: 30 * time.Second, maxConns: 100} // defaults
	for _, opt := range opts {
		opt(s)
	}
	return s
}

func main() {
	s := NewServer(":8080", WithTimeout(5*time.Second))
	fmt.Printf("%+v\n", *s)
}
```

The benefits: defaults live in one place, new options don't change the signature, and call sites read well.

## Method values and method expressions

A method bound to a specific value (`object.Method`) is a **method value**: an ordinary function that remembers its receiver. `Type.Method` is a **method expression**: the receiver becomes the first parameter.

```go
package main

import "fmt"

type Counter struct{ n int }

func (c *Counter) Inc() { c.n++ }

func thrice(f func()) {
	for range 3 {
		f()
	}
}

func main() {
	c := &Counter{}
	thrice(c.Inc)    // method value: the receiver c is bound
	fmt.Println(c.n) // 3

	inc := (*Counter).Inc // method expression: func(*Counter)
	inc(c)
	fmt.Println(c.n) // 4
}
```

Careful: a method value evaluates its receiver **when it's created**. If the receiver is a value (not a pointer), a copy is made at that moment.

## Closures that hold state

Closures are a lightweight alternative to structs with a single method:

```go
package main

import "fmt"

func fibonacci() func() int {
	a, b := 0, 1
	return func() int {
		r := a
		a, b = b, a+b
		return r
	}
}

func memo(f func(int) int) func(int) int {
	cache := map[int]int{}
	return func(n int) int {
		if v, ok := cache[n]; ok {
			return v
		}
		v := f(n)
		cache[n] = v
		return v
	}
}

func main() {
	fib := fibonacci()
	for range 8 {
		fmt.Print(fib(), " ")
	}
	fmt.Println()

	square := memo(func(n int) int {
		fmt.Println("computing", n)
		return n * n
	})
	fmt.Println(square(4), square(4)) // "computing 4" appears only once
}
```

Captured state isn't protected against concurrent access: if the closure is called from several goroutines, you need a mutex.

## Recursive anonymous functions

An anonymous function can't call itself by name. Declare the variable first, then assign the function:

```go
package main

import "fmt"

func main() {
	var fact func(int) int
	fact = func(n int) int {
		if n <= 1 {
			return 1
		}
		return n * fact(n-1)
	}
	fmt.Println(fact(10))
}
```

## Summary

- `type F func(...)` + a method = an adapter from function to interface.
- Middleware wraps functions with the same type.
- Functional options: defaults in one place, extensible options.
- `x.M` binds the receiver; `T.M` makes it the first parameter.
- State in closures needs synchronization when used concurrently.
