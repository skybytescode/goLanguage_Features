# Funcții și closures — Practician

Funcțiile ca valori permit câteva pattern-uri foarte răspândite în Go: tipurile-funcție care implementează interfețe, middleware, „functional options” și method values.

## Tipuri-funcție

Poți defini un tip pe baza unei semnături și îi poți adăuga metode. Așa funcționează `http.HandlerFunc`: o funcție obișnuită devine un `http.Handler`.

```go
package main

import "fmt"

type Validator interface {
	Valid(s string) bool
}

// ValidatorFunc adaptează o funcție la interfața Validator.
type ValidatorFunc func(string) bool

func (f ValidatorFunc) Valid(s string) bool { return f(s) }

func verifica(v Validator, valori ...string) {
	for _, s := range valori {
		fmt.Printf("%q: %t\n", s, v.Valid(s))
	}
}

func main() {
	nevid := ValidatorFunc(func(s string) bool { return s != "" })
	verifica(nevid, "abc", "")
}
```

## Middleware: funcții care învelesc funcții

O funcție care primește o funcție și întoarce alta, cu același tip, poate adăuga comportament (logare, cronometrare, reîncercări) fără să modifice codul original:

```go
package main

import (
	"fmt"
	"strings"
)

type Transform func(string) string

func cuLog(nume string, f Transform) Transform {
	return func(s string) string {
		rez := f(s)
		fmt.Printf("%s(%q) = %q\n", nume, s, rez)
		return rez
	}
}

func lant(fs ...Transform) Transform {
	return func(s string) string {
		for _, f := range fs {
			s = f(s)
		}
		return s
	}
}

func main() {
	t := lant(
		cuLog("trim", strings.TrimSpace),
		cuLog("upper", strings.ToUpper),
	)
	fmt.Println(t("  salut  "))
}
```

`strings.TrimSpace` are exact tipul `func(string) string`, deci se potrivește direct cu `Transform`.

## Functional options

Pentru constructori cu multe setări opționale, Go folosește des pattern-ul **functional options**: fiecare opțiune e o funcție care modifică configurația.

```go
package main

import (
	"fmt"
	"time"
)

type Server struct {
	adresa  string
	timeout time.Duration
	maxConn int
}

type Optiune func(*Server)

func CuTimeout(d time.Duration) Optiune {
	return func(s *Server) { s.timeout = d }
}

func CuMaxConn(n int) Optiune {
	return func(s *Server) { s.maxConn = n }
}

func NouServer(adresa string, opts ...Optiune) *Server {
	s := &Server{adresa: adresa, timeout: 30 * time.Second, maxConn: 100} // valori implicite
	for _, opt := range opts {
		opt(s)
	}
	return s
}

func main() {
	s := NouServer(":8080", CuTimeout(5*time.Second))
	fmt.Printf("%+v\n", *s)
}
```

Avantajele: valorile implicite stau într-un singur loc, opțiunile noi nu schimbă semnătura, iar apelurile se citesc ușor.

## Method values și method expressions

O metodă legată de o valoare anume (`obiect.Metoda`) e un **method value**: o funcție obișnuită, care își amintește receptorul. `Tip.Metoda` e un **method expression**: receptorul devine primul parametru.

```go
package main

import "fmt"

type Contor struct{ n int }

func (c *Contor) Inc() { c.n++ }

func deTrei(f func()) {
	for range 3 {
		f()
	}
}

func main() {
	c := &Contor{}
	deTrei(c.Inc)    // method value: receptorul c e legat
	fmt.Println(c.n) // 3

	inc := (*Contor).Inc // method expression: func(*Contor)
	inc(c)
	fmt.Println(c.n) // 4
}
```

Atenție: un method value evaluează receptorul **în momentul creării**. Dacă receptorul e o valoare (nu pointer), se face o copie atunci.

## Closures care țin stare

Closure-urile sunt o alternativă ușoară la structuri cu o singură metodă:

```go
package main

import "fmt"

func fibonacci() func() int {
	a, b := 0, 1
	return func() int {
		r := a
		a, b = b, a+b
		return r
	}
}

func memo(f func(int) int) func(int) int {
	cache := map[int]int{}
	return func(n int) int {
		if v, ok := cache[n]; ok {
			return v
		}
		v := f(n)
		cache[n] = v
		return v
	}
}

func main() {
	fib := fibonacci()
	for range 8 {
		fmt.Print(fib(), " ")
	}
	fmt.Println()

	patrat := memo(func(n int) int {
		fmt.Println("calculez", n)
		return n * n
	})
	fmt.Println(patrat(4), patrat(4)) // „calculez 4” apare o singură dată
}
```

Starea capturată nu e protejată pentru acces concurent: dacă closure-ul e apelat din mai multe goroutines, ai nevoie de un mutex.

## Funcții recursive anonime

O funcție anonimă nu se poate apela pe nume. Declari întâi variabila, apoi îi atribui funcția:

```go
package main

import "fmt"

func main() {
	var fact func(int) int
	fact = func(n int) int {
		if n <= 1 {
			return 1
		}
		return n * fact(n-1)
	}
	fmt.Println(fact(10))
}
```

## Pe scurt

- `type F func(...)` + metodă = adaptor de la funcție la interfață.
- Middleware-ul învelește funcții cu același tip.
- Functional options: valori implicite într-un loc, opțiuni extensibile.
- `x.M` leagă receptorul; `T.M` îl face primul parametru.
- Starea din closures are nevoie de sincronizare dacă e folosită concurent.
