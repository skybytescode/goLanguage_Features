# net/http — Practician

Ce transformă un server de exemplu într-unul de producție: middleware, timeout-uri, limitarea corpului cererii, oprirea grațioasă, un client configurat corect și testarea handler-elor.

## Middleware

Un middleware e o funcție care primește un `http.Handler` și întoarce altul, adăugând comportament înainte sau după:

```go
package main

import (
	"fmt"
	"log"
	"net/http"
	"net/http/httptest"
	"os"
	"time"
)

func logare(urm http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		start := time.Now()
		urm.ServeHTTP(w, r)
		log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(start).Round(time.Microsecond))
	})
}

func recuperare(urm http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if err := recover(); err != nil {
				http.Error(w, "eroare internă", http.StatusInternalServerError)
			}
		}()
		urm.ServeHTTP(w, r)
	})
}

func main() {
	log.SetOutput(os.Stdout)
	log.SetFlags(0)

	mux := http.NewServeMux()
	mux.HandleFunc("GET /ok", func(w http.ResponseWriter, r *http.Request) { fmt.Fprint(w, "ok") })
	mux.HandleFunc("GET /bum", func(w http.ResponseWriter, r *http.Request) { panic("bug") })

	srv := httptest.NewServer(logare(recuperare(mux))) // ordinea: din exterior spre interior
	defer srv.Close()

	for _, p := range []string{"/ok", "/bum"} {
		resp, _ := http.Get(srv.URL + p)
		resp.Body.Close()
		fmt.Println(p, resp.StatusCode)
	}
}
```

Serverul HTTP are deja un `recover` intern care previne oprirea procesului, dar închide conexiunea fără răspuns. Middleware-ul de mai sus trimite un 500 curat.

## Timeout-uri pe server

`http.ListenAndServe` folosește un server **fără timeout-uri**: un client lent (sau rău intenționat) poate ține conexiuni deschise la nesfârșit. În producție, configurează `http.Server`:

```go,ignore
srv := &http.Server{
	Addr:              ":8080",
	Handler:           mux,
	ReadHeaderTimeout: 5 * time.Second,  // protecție împotriva Slowloris
	ReadTimeout:       15 * time.Second, // tot request-ul, inclusiv corpul
	WriteTimeout:      30 * time.Second, // de la sfârșitul citirii headerelor până la final
	IdleTimeout:       2 * time.Minute,  // conexiuni keep-alive inactive
	MaxHeaderBytes:    1 << 20,
}
```

Pentru un handler care are nevoie de mai mult timp (un upload mare, un stream), `http.NewResponseController(w).SetWriteDeadline(...)` (Go 1.20) schimbă termenul doar pentru cererea respectivă.

## Limitarea și decodarea corpului

```go
package main

import (
	"encoding/json"
	"errors"
	"fmt"
	"net/http"
	"net/http/httptest"
	"strings"
)

type Utilizator struct {
	Nume  string `json:"nume"`
	Email string `json:"email"`
}

func creeaza(w http.ResponseWriter, r *http.Request) {
	r.Body = http.MaxBytesReader(w, r.Body, 1<<20) // cel mult 1 MiB
	dec := json.NewDecoder(r.Body)
	dec.DisallowUnknownFields()

	var u Utilizator
	if err := dec.Decode(&u); err != nil {
		var prea *http.MaxBytesError
		if errors.As(err, &prea) {
			http.Error(w, "corp prea mare", http.StatusRequestEntityTooLarge)
			return
		}
		http.Error(w, "JSON invalid: "+err.Error(), http.StatusBadRequest)
		return
	}
	if u.Email == "" {
		http.Error(w, "email obligatoriu", http.StatusUnprocessableEntity)
		return
	}
	w.WriteHeader(http.StatusCreated)
	fmt.Fprintf(w, "creat %s\n", u.Nume)
}

func main() {
	for _, corp := range []string{`{"nume":"Ana","email":"a@x.ro"}`, `{"nume":"Ion"}`, `{"nme":"x"}`} {
		req := httptest.NewRequest("POST", "/utilizatori", strings.NewReader(corp))
		rec := httptest.NewRecorder()
		creeaza(rec, req)
		fmt.Print(rec.Code, " ", rec.Body.String())
	}
}
```

Fără `MaxBytesReader`, un client poate trimite un corp de câțiva GB și epuiza memoria.

## Contextul cererii

`r.Context()` se anulează când clientul închide conexiunea. Transmite-l mai departe (bază de date, alte servicii), ca munca inutilă să se oprească:

```go,ignore
func raport(w http.ResponseWriter, r *http.Request) {
	rez, err := db.QueryContext(r.Context(), "SELECT ...")
	if errors.Is(err, context.Canceled) {
		return // clientul a plecat; nimeni nu mai așteaptă răspunsul
	}
	// ...
}
```

## Oprirea grațioasă

La un semnal de oprire (deploy, scalare), serverul trebuie să nu mai accepte conexiuni noi, dar să termine cererile în curs:

```go,ignore
func main() {
	srv := &http.Server{Addr: ":8080", Handler: mux}

	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
	defer stop()

	go func() {
		if err := srv.ListenAndServe(); err != nil && !errors.Is(err, http.ErrServerClosed) {
			log.Fatal(err)
		}
	}()

	<-ctx.Done() // a sosit semnalul
	shutdownCtx, cancel := context.WithTimeout(context.Background(), 20*time.Second)
	defer cancel()
	if err := srv.Shutdown(shutdownCtx); err != nil {
		log.Println("oprire forțată:", err)
	}
}
```

## Clientul, configurat corect

- **Un singur `http.Client`** refolosit în toată aplicația: el ține pool-ul de conexiuni (keep-alive). Un client nou per cerere înseamnă conexiuni TCP și handshake-uri TLS noi de fiecare dată.
- **Timeout** pe client sau context pe cerere (`http.NewRequestWithContext`).
- **Corpul răspunsului** trebuie citit **până la capăt** și închis, ca conexiunea să revină în pool. `io.Copy(io.Discard, resp.Body)` înainte de `Close`, dacă nu ai nevoie de el.
- `Transport.MaxIdleConnsPerHost` (implicit 2) e prea mic pentru un client care face multe cereri concurente către același serviciu.

## Testarea handler-elor

`httptest.NewRecorder` capturează răspunsul fără rețea; `httptest.NewServer` pornește un server real pe loopback pentru teste end-to-end (inclusiv pentru clienți):

```go,ignore
func TestSanatate(t *testing.T) {
	req := httptest.NewRequest("GET", "/sanatate", nil)
	rec := httptest.NewRecorder()
	handler(rec, req)

	if rec.Code != http.StatusOK {
		t.Fatalf("cod %d, vreau 200", rec.Code)
	}
}
```

## Pe scurt

- Middleware = `func(http.Handler) http.Handler`, compus din exterior spre interior.
- Configurează `http.Server` cu timeout-uri; `ListenAndServe` simplu nu are.
- `MaxBytesReader` + `DisallowUnknownFields` + validare pentru corpuri JSON.
- `Shutdown` pentru oprire grațioasă; `r.Context()` pentru anulare.
- Un singur client, cu timeout, cu corpul citit și închis.
