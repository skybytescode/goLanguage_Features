# net/http — Fundamente

Biblioteca standard a Go conține un server și un client HTTP gata de producție. Multe servicii Go nu folosesc niciun framework: doar `net/http`.

## Primul server

```go,ignore
package main

import (
	"fmt"
	"log"
	"net/http"
)

func salut(w http.ResponseWriter, r *http.Request) {
	fmt.Fprintln(w, "Salut, lume!")
}

func main() {
	http.HandleFunc("/", salut)
	log.Println("ascult pe http://localhost:8080")
	log.Fatal(http.ListenAndServe(":8080", nil))
}
```

Un **handler** primește:

- `w http.ResponseWriter` — unde scrii răspunsul (e un `io.Writer`);
- `r *http.Request` — cererea: metoda, URL-ul, antetele, corpul.

Fiecare cerere e tratată în propria **goroutine**, deci serverul servește automat mai mulți clienți simultan.

> Exemplele de pe această pagină folosesc `httptest`, care pornește un server temporar în același program, ca să poată fi rulate oriunde. În aplicația ta, folosești `http.ListenAndServe` ca mai sus.

## Rute cu metodă și parametri (Go 1.22)

`http.ServeMux` acceptă tipare cu **metoda HTTP** și **parametri** în cale:

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func main() {
	mux := http.NewServeMux()
	mux.HandleFunc("GET /produse/{id}", func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprintf(w, "produsul %s\n", r.PathValue("id"))
	})
	mux.HandleFunc("POST /produse", func(w http.ResponseWriter, r *http.Request) {
		w.WriteHeader(http.StatusCreated)
		fmt.Fprintln(w, "creat")
	})

	srv := httptest.NewServer(mux)
	defer srv.Close()

	resp, _ := http.Get(srv.URL + "/produse/42")
	corp, _ := io.ReadAll(resp.Body)
	resp.Body.Close()
	fmt.Print(resp.StatusCode, " ", string(corp)) // 200 produsul 42

	resp, _ = http.Post(srv.URL+"/produse/42", "text/plain", nil)
	resp.Body.Close()
	fmt.Println(resp.StatusCode) // 405: POST nu e permis pe această rută
}
```

## Parametri din query string

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

func cauta(w http.ResponseWriter, r *http.Request) {
	q := r.URL.Query().Get("q")
	if q == "" {
		http.Error(w, "lipsește parametrul q", http.StatusBadRequest)
		return
	}
	fmt.Fprintf(w, "rezultate pentru %q\n", q)
}

func main() {
	srv := httptest.NewServer(http.HandlerFunc(cauta))
	defer srv.Close()

	for _, url := range []string{"/?q=golang", "/"} {
		resp, _ := http.Get(srv.URL + url)
		b, _ := io.ReadAll(resp.Body)
		resp.Body.Close()
		fmt.Print(resp.StatusCode, " ", string(b))
	}
}
```

`http.Error` setează codul de stare și scrie mesajul. După el, nu uita `return`.

## Răspuns JSON

```go
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
)

type Stare struct {
	Status   string `json:"status"`
	Versiune string `json:"versiune"`
}

func sanatate(w http.ResponseWriter, r *http.Request) {
	w.Header().Set("Content-Type", "application/json") // antetele ÎNAINTE de corp
	json.NewEncoder(w).Encode(Stare{Status: "ok", Versiune: "1.0"})
}

func main() {
	srv := httptest.NewServer(http.HandlerFunc(sanatate))
	defer srv.Close()

	resp, _ := http.Get(srv.URL)
	defer resp.Body.Close()
	b, _ := io.ReadAll(resp.Body)
	fmt.Print(resp.Header.Get("Content-Type"), " ", string(b))
}
```

Ordinea contează: antetele, apoi `WriteHeader` (opțional, implicit 200), apoi corpul. Odată ce ai scris în corp, antetele nu mai pot fi schimbate.

## Clientul HTTP

```go
package main

import (
	"fmt"
	"io"
	"net/http"
	"net/http/httptest"
	"time"
)

func main() {
	srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		fmt.Fprint(w, "pong")
	}))
	defer srv.Close()

	client := &http.Client{Timeout: 5 * time.Second} // setează MEREU un timeout
	resp, err := client.Get(srv.URL)
	if err != nil {
		fmt.Println("eroare:", err)
		return
	}
	defer resp.Body.Close() // obligatoriu: altfel conexiunea nu e refolosită

	if resp.StatusCode != http.StatusOK {
		fmt.Println("status neașteptat:", resp.Status)
		return
	}
	b, _ := io.ReadAll(resp.Body)
	fmt.Println(string(b))
}
```

Atenție: `http.Get` întoarce `err == nil` și pentru un 404 sau 500. Eroarea apare doar când nu s-a putut obține deloc un răspuns; codul de stare îl verifici tu.

## Pe scurt

- Un handler primește `ResponseWriter` și `*Request`; fiecare cerere are goroutine-ul ei.
- `ServeMux` suportă `"GET /cale/{param}"` din Go 1.22; `r.PathValue` citește parametrul.
- Antetele se setează înainte de corp; `http.Error` + `return` pentru erori.
- Clientul are nevoie de un `Timeout` și de `defer resp.Body.Close()`.
- Un 404 nu e o eroare de rețea: verifică `resp.StatusCode`.
