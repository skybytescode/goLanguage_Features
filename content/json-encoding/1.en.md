# JSON and encoding — Fundamentals

The `encoding/json` package turns Go structs into JSON (**marshal**) and back (**unmarshal**). It's used in almost every web API written in Go.

## From Go to JSON: `json.Marshal`

```go
package main

import (
	"encoding/json"
	"fmt"
)

type User struct {
	Name   string
	Age    int
	Active bool
}

func main() {
	u := User{Name: "Ana", Age: 30, Active: true}
	data, err := json.Marshal(u)
	if err != nil {
		fmt.Println(err)
		return
	}
	fmt.Println(string(data)) // {"Name":"Ana","Age":30,"Active":true}
}
```

`json.Marshal` returns `[]byte`. Only **exported** fields (uppercase) appear in the JSON.

## Tags: the names in JSON

You usually want JSON-style names (`name`, `created_at`). You set them with **tags**:

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Product struct {
	ID       int      `json:"id"`
	Name     string   `json:"name"`
	Price    float64  `json:"price"`
	Tags     []string `json:"tags"`
	Internal string   `json:"-"` // never in JSON
}

func main() {
	p := Product{ID: 7, Name: "Book", Price: 49.9, Tags: []string{"new"}, Internal: "secret"}
	data, _ := json.MarshalIndent(p, "", "  ") // pretty-printed
	fmt.Println(string(data))
}
```

## From JSON to Go: `json.Unmarshal`

Give it the bytes and a **pointer** to the variable to fill:

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Order struct {
	ID       int      `json:"id"`
	Customer string   `json:"customer"`
	Items    []string `json:"items"`
	Paid     bool     `json:"paid"`
}

func main() {
	text := `{"id": 101, "customer": "Ion", "items": ["bread", "milk"], "paid": true, "extra": 1}`

	var o Order
	if err := json.Unmarshal([]byte(text), &o); err != nil {
		fmt.Println("invalid JSON:", err)
		return
	}
	fmt.Printf("%+v\n", o)
}
```

JSON fields with no matching struct field (`extra`) are **ignored**. Struct fields missing from the JSON keep their zero value.

## Nested structs and lists

```go
package main

import (
	"encoding/json"
	"fmt"
)

type Address struct {
	City   string `json:"city"`
	Street string `json:"street"`
}

type Person struct {
	Name    string   `json:"name"`
	Address Address  `json:"address"`
	Phones  []string `json:"phones"`
}

func main() {
	text := `[
		{"name": "Ana", "address": {"city": "Cluj", "street": "Unirii"}, "phones": ["0711"]},
		{"name": "Ion", "address": {"city": "Iași", "street": "Păcurari"}}
	]`
	var people []Person
	if err := json.Unmarshal([]byte(text), &people); err != nil {
		fmt.Println(err)
		return
	}
	for _, p := range people {
		fmt.Println(p.Name, "from", p.Address.City, p.Phones)
	}
}
```

## Unknown JSON: `map[string]any`

If you don't know the structure up front, you can decode into a map. Numbers become `float64`, objects `map[string]any`, lists `[]any`:

```go
package main

import (
	"encoding/json"
	"fmt"
)

func main() {
	var data map[string]any
	json.Unmarshal([]byte(`{"name": "Go", "version": 1.26, "tags": ["fast", "simple"]}`), &data)

	fmt.Println(data["name"])
	fmt.Printf("%T\n", data["version"]) // float64
	for _, t := range data["tags"].([]any) {
		fmt.Println("-", t)
	}
}
```

The code fills up with type assertions; prefer structs when you know the shape of the data.

## Go types and JSON types

| Go | JSON |
|---|---|
| `bool` | `true` / `false` |
| numbers (`int`, `float64`…) | number |
| `string` | string |
| `[]T`, array | list (`[]`); a `nil` slice → `null` |
| `struct`, `map[string]T` | object (`{}`) |
| `nil` pointer, `nil` interface | `null` |
| `time.Time` | RFC 3339 string (`"2026-10-19T12:00:00Z"`) |
| `[]byte` | base64 string |

## Summary

- `json.Marshal` / `json.MarshalIndent` from Go to JSON.
- `json.Unmarshal(data, &v)` from JSON to Go; give it a pointer.
- Only exported fields are serialized; tags set the names.
- `json:"-"` excludes a field.
- `map[string]any` for unknown JSON, but prefer structs.
