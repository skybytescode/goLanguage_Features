# Interfaces — Practitioner

Good interfaces in Go are **small** and defined **where they're used**. This is also where the language's most famous trap shows up: the interface that isn't `nil` even though it holds a `nil` pointer.

## Small interfaces

The most used interfaces in the standard library have a single method:

```go,ignore
type Reader interface { Read(p []byte) (n int, err error) }
type Writer interface { Write(p []byte) (n int, err error) }
type Stringer interface { String() string }
type error interface { Error() string }
```

The smaller the interface, the more types implement it and the easier it is to replace in tests. Bigger interfaces are composed from small ones:

```go,ignore
type ReadWriter interface {
	Reader
	Writer
}
```

## "Accept interfaces, return structs"

- Parameters: ask for the **minimum** behavior you need (an interface).
- Results: return the **concrete** type, so the caller gets access to everything.

```go
package main

import (
	"fmt"
	"io"
	"os"
	"strings"
)

// count accepts any source of bytes: a file, the network, a string, a buffer...
func count(r io.Reader) (int, error) {
	data, err := io.ReadAll(r)
	return len(strings.Fields(string(data))), err
}

func main() {
	n, _ := count(strings.NewReader("one two three"))
	fmt.Println(n)

	fmt.Fprintln(os.Stdout, "os.Stdout is an io.Writer")
}
```

## Interfaces are defined by the consumer

In Java, the interface lives next to the implementation. In Go, implicit implementation allows the opposite: the package that **uses** a behavior declares the interface it needs. The package that provides it just returns a concrete type.

```go,ignore
// package notifications: declares only what it uses
type Sender interface {
	Send(to, message string) error
}

func Announce(s Sender, users []string) error { ... }
```

Any SMTP client, SMS client or test mock with a `Send` method works, without their packages knowing about `notifications`.

## Compile-time check

Because implementation is implicit, it's easy to break an interface by changing a signature. A line like this stops compilation if the type no longer implements the interface:

```go
package main

import (
	"fmt"
	"io"
)

type Counter struct{ n int }

func (c *Counter) Write(p []byte) (int, error) {
	c.n += len(p)
	return len(p), nil
}

var _ io.Writer = (*Counter)(nil) // compile-time check, no run-time cost

func main() {
	c := &Counter{}
	fmt.Fprintf(c, "hello %s", "world")
	fmt.Println(c.n) // 11
}
```

## Pointer receivers: only `*T` implements

If the methods are defined on `*T`, the value `T` does **not** implement the interface:

```go,compile_fail
package main

import "io"

type Counter struct{ n int }

func (c *Counter) Write(p []byte) (int, error) { return len(p), nil }

func main() {
	var w io.Writer = Counter{} // error: Write has pointer receiver
	_ = w
}
```

The reason: a value stored in an interface isn't addressable, so Go can't take its address to call the method.

## The trap: a non-nil interface holding nil

An interface has two components: the dynamic **type** and the **value**. It's `nil` only if **both** are missing. A `nil` pointer stored in an interface produces an interface with a type, so it's **non-nil**:

```go
package main

import "fmt"

type MyError struct{}

func (*MyError) Error() string { return "error" }

func check(ok bool) error {
	var e *MyError // nil
	if !ok {
		e = &MyError{}
	}
	return e // WRONG: returns an interface with type *MyError and a nil value
}

func main() {
	err := check(true)
	fmt.Println(err == nil) // false!
	fmt.Printf("%T %v\n", err, err == (*MyError)(nil))
}
```

The rule: in a function that returns `error`, write `return nil` explicitly on the success path; don't return a variable of a concrete pointer type.

## Interface upgrades

A function can check at run time whether the value it got offers **more** than the minimal interface, and take a faster path. That's what `io.Copy` does with `io.WriterTo` and `io.ReaderFrom`:

```go
package main

import (
	"fmt"
	"strings"
)

type Lener interface{ Len() int }

func size(s fmt.Stringer) int {
	if l, ok := s.(Lener); ok {
		return l.Len() // fast path
	}
	return len(s.String())
}

type Name string

func (n Name) String() string { return string(n) }

func main() {
	var b strings.Builder
	b.WriteString("abc")
	fmt.Println(size(&b), size(Name("Go")))
}
```

## Summary

- Small interfaces, composed by embedding.
- Interface parameters, concrete results.
- The interface is declared in the package that uses it.
- `var _ I = (*T)(nil)` checks the implementation at compile time.
- Don't return a concrete `nil` pointer as an `error`.
