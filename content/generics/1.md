# Generics — Fundamente

Din Go 1.18, funcțiile și tipurile pot avea **parametri de tip**. Scrii codul o singură dată și îl folosești cu mai multe tipuri, păstrând verificarea la compilare.

## Problema

Fără generics, pentru a găsi maximul unui slice de `int` și al unuia de `float64` ai nevoie de două funcții identice, sau de `any` și conversii la rulare:

```go,ignore
func MaxInt(s []int) int { ... }
func MaxFloat(s []float64) float64 { ... }
```

## O funcție generică

Parametrii de tip stau între paranteze pătrate, înaintea parametrilor obișnuiți. Fiecare are o **constrângere** care spune ce tipuri sunt permise:

```go
package main

import (
	"cmp"
	"fmt"
)

func Max[T cmp.Ordered](s []T) T {
	m := s[0]
	for _, v := range s[1:] {
		if v > m {
			m = v
		}
	}
	return m
}

func main() {
	fmt.Println(Max([]int{3, 7, 2}))          // 7
	fmt.Println(Max([]float64{1.5, 0.2}))     // 1.5
	fmt.Println(Max([]string{"mar", "pere"})) // pere
}
```

`cmp.Ordered` include toate tipurile care suportă `<` și `>`: numere și stringuri.

## Deducerea tipului

În exemplul de mai sus nu am scris `Max[int](...)`: compilatorul a dedus `T` din argumente. Poți scrie tipul explicit când nu se poate deduce:

```go
package main

import "fmt"

func Zero[T any]() T {
	var z T // valoarea zero a lui T
	return z
}

func main() {
	fmt.Println(Zero[int]())           // 0
	fmt.Printf("%q\n", Zero[string]()) // ""
}
```

## Constrângeri de bază

| Constrângere | Ce permite |
|---|---|
| `any` | orice tip; poți doar atribui, transmite, întoarce |
| `comparable` | tipuri care suportă `==` și `!=` (pot fi chei de map) |
| `cmp.Ordered` | tipuri cu `<`, `<=`, `>`, `>=` |

```go
package main

import "fmt"

func Contine[T comparable](s []T, x T) bool {
	for _, v := range s {
		if v == x {
			return true
		}
	}
	return false
}

func main() {
	fmt.Println(Contine([]string{"a", "b"}, "b")) // true
	fmt.Println(Contine([]int{1, 2}, 5))          // false
}
```

## Funcții cu mai mulți parametri de tip

```go
package main

import (
	"fmt"
	"strconv"
)

func Map[T, U any](s []T, f func(T) U) []U {
	rez := make([]U, 0, len(s))
	for _, v := range s {
		rez = append(rez, f(v))
	}
	return rez
}

func main() {
	numere := []int{1, 2, 3}
	texte := Map(numere, strconv.Itoa)
	fmt.Printf("%q\n", texte) // ["1" "2" "3"]
}
```

## Tipuri generice

Și tipurile pot avea parametri. O stivă care funcționează cu orice tip:

```go
package main

import "fmt"

type Stiva[T any] struct {
	elemente []T
}

func (s *Stiva[T]) Push(v T) {
	s.elemente = append(s.elemente, v)
}

func (s *Stiva[T]) Pop() (T, bool) {
	var zero T
	if len(s.elemente) == 0 {
		return zero, false
	}
	v := s.elemente[len(s.elemente)-1]
	s.elemente = s.elemente[:len(s.elemente)-1]
	return v, true
}

func main() {
	var s Stiva[string]
	s.Push("a")
	s.Push("b")
	v, _ := s.Pop()
	fmt.Println(v) // b
}
```

Când folosești tipul, îi dai argumentul: `Stiva[string]`, `Stiva[int]`.

## Generics în biblioteca standard

Ai folosit deja generics fără să știi: `slices.Sort`, `slices.Contains`, `maps.Keys`, `min`, `max` sunt toate generice.

## Pe scurt

- `func F[T Constrangere](x T)` declară un parametru de tip.
- Tipul e de obicei dedus din argumente.
- `any`, `comparable` și `cmp.Ordered` acoperă majoritatea cazurilor.
- `var zero T` dă valoarea zero a unui tip generic.
- Tipurile generice se instanțiază cu `Tip[Argument]`.
