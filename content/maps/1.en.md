# Maps — Fundamentals

A **map** associates keys with values, like a dictionary. Lookup, insertion and deletion are fast, no matter how many elements it has.

## Creating a map

The type is written `map[KeyType]ValueType`:

```go
package main

import "fmt"

func main() {
	ages := map[string]int{
		"Ana": 30,
		"Ion": 25,
	}
	ages["Maria"] = 28 // insert
	ages["Ion"] = 26   // update

	fmt.Println(ages["Ana"]) // 30
	fmt.Println(len(ages))   // 3
}
```

You can also create an empty map with `make`:

```go
package main

import "fmt"

func main() {
	stock := make(map[string]int)
	stock["apples"] = 10
	fmt.Println(stock)
}
```

## Missing key: the zero value

Reading a key that doesn't exist isn't an error: it returns the type's zero value. To know whether the key exists, use the **comma-ok** form:

```go
package main

import "fmt"

func main() {
	prices := map[string]float64{"bread": 4.5}

	fmt.Println(prices["milk"]) // 0: the key doesn't exist

	price, ok := prices["milk"]
	if !ok {
		fmt.Println("no milk")
	} else {
		fmt.Println("milk:", price)
	}
}
```

## Deleting

`delete` removes a key. If it doesn't exist, nothing happens:

```go
package main

import "fmt"

func main() {
	m := map[string]int{"a": 1, "b": 2}
	delete(m, "a")
	delete(m, "z") // no effect, no error
	fmt.Println(m) // map[b:2]
}
```

## Iterating

`range` gives the key and the value. **The order isn't guaranteed** and differs from run to run:

```go
package main

import "fmt"

func main() {
	capitals := map[string]string{
		"Romania": "Bucharest",
		"France":  "Paris",
		"Italy":   "Rome",
	}
	for country, capital := range capitals {
		fmt.Printf("%s → %s\n", country, capital)
	}
}
```

`fmt.Println`, however, prints the keys sorted, so they're easy to read.

## Counting with a map

Since a missing key returns 0, counting is very simple:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "the cat and the dog and the bird"
	freq := map[string]int{}
	for _, word := range strings.Fields(text) {
		freq[word]++
	}
	fmt.Println(freq) // map[and:2 bird:1 cat:1 dog:1 the:3]
}
```

## The nil map

The zero value of a map is `nil`. You can read from it (it returns zero values), but **writing panics**:

```go,panic
package main

import "fmt"

func main() {
	var m map[string]int
	fmt.Println(m["x"], len(m)) // 0 0: reading is fine
	m["x"] = 1                  // panic: assignment to entry in nil map
}
```

Always initialize the map with `make` or a literal before writing to it.

## What can be a key

The key must be a type **comparable** with `==`: numbers, strings, bools, pointers, and structs and arrays made of such types. Slices, maps and functions **can't** be keys.

## Complex values

Values can be any type, including slices or other maps:

```go
package main

import "fmt"

func main() {
	groups := map[string][]string{}
	groups["fruit"] = append(groups["fruit"], "apple", "pear")
	groups["vegetables"] = append(groups["vegetables"], "carrot")
	fmt.Println(groups)
}
```

`append` on a `nil` slice works, so you don't need to initialize each list.

## Summary

- `map[K]V`: create with a literal or `make`.
- `v, ok := m[k]` tells you whether the key exists.
- `delete(m, k)` deletes; `len(m)` counts.
- `range` order is random.
- Writing to a `nil` map panics.
