# Maps — Fundamente

Un **map** asociază chei cu valori, ca un dicționar. Căutarea, adăugarea și ștergerea sunt rapide, indiferent câte elemente are.

## Crearea unui map

Tipul se scrie `map[TipCheie]TipValoare`:

```go
package main

import "fmt"

func main() {
	varste := map[string]int{
		"Ana": 30,
		"Ion": 25,
	}
	varste["Maria"] = 28 // adăugare
	varste["Ion"] = 26   // modificare

	fmt.Println(varste["Ana"]) // 30
	fmt.Println(len(varste))   // 3
}
```

Poți crea și un map gol cu `make`:

```go
package main

import "fmt"

func main() {
	stoc := make(map[string]int)
	stoc["mere"] = 10
	fmt.Println(stoc)
}
```

## Cheie lipsă: valoarea zero

Citirea unei chei care nu există nu dă eroare: întoarce valoarea zero a tipului. Ca să știi dacă cheia există, folosește forma **comma-ok**:

```go
package main

import "fmt"

func main() {
	preturi := map[string]float64{"pâine": 4.5}

	fmt.Println(preturi["lapte"]) // 0: cheia nu există

	pret, ok := preturi["lapte"]
	if !ok {
		fmt.Println("nu avem lapte")
	} else {
		fmt.Println("lapte:", pret)
	}
}
```

## Ștergerea

`delete` scoate o cheie. Dacă ea nu există, nu se întâmplă nimic:

```go
package main

import "fmt"

func main() {
	m := map[string]int{"a": 1, "b": 2}
	delete(m, "a")
	delete(m, "z") // fără efect, fără eroare
	fmt.Println(m) // map[b:2]
}
```

## Parcurgerea

`range` dă cheia și valoarea. **Ordinea nu e garantată** și diferă de la o rulare la alta:

```go
package main

import "fmt"

func main() {
	capitale := map[string]string{
		"România": "București",
		"Franța":  "Paris",
		"Italia":  "Roma",
	}
	for tara, capitala := range capitale {
		fmt.Printf("%s → %s\n", tara, capitala)
	}
}
```

`fmt.Println` afișează însă cheile sortate, ca să fie ușor de citit.

## Numărarea cu un map

Pentru că o cheie lipsă întoarce 0, numărarea e foarte simplă:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "a fost odata ca niciodata a fost"
	frecventa := map[string]int{}
	for _, cuvant := range strings.Fields(text) {
		frecventa[cuvant]++
	}
	fmt.Println(frecventa) // map[a:2 ca:1 fost:2 niciodata:1 odata:1]
}
```

## Map-ul nil

Valoarea zero a unui map e `nil`. Poți citi din el (întoarce valori zero), dar **scrierea dă panic**:

```go,panic
package main

import "fmt"

func main() {
	var m map[string]int
	fmt.Println(m["x"], len(m)) // 0 0: citirea e ok
	m["x"] = 1                  // panic: assignment to entry in nil map
}
```

Inițializează mereu map-ul cu `make` sau cu un literal înainte să scrii în el.

## Ce poate fi cheie

Cheia trebuie să fie un tip **comparabil** cu `==`: numere, string-uri, bool, pointeri, structuri și array-uri din astfel de tipuri. Slices, maps și funcțiile **nu** pot fi chei.

## Valori complexe

Valorile pot fi de orice tip, inclusiv slices sau alte maps:

```go
package main

import "fmt"

func main() {
	grupuri := map[string][]string{}
	grupuri["fructe"] = append(grupuri["fructe"], "măr", "pară")
	grupuri["legume"] = append(grupuri["legume"], "morcov")
	fmt.Println(grupuri)
}
```

`append` pe un slice `nil` funcționează, deci nu trebuie să inițializezi fiecare listă.

## Pe scurt

- `map[K]V`: creare cu literal sau `make`.
- `v, ok := m[k]` spune dacă cheia există.
- `delete(m, k)` șterge; `len(m)` numără.
- Ordinea la `range` e aleatoare.
- Scrierea într-un map `nil` dă panic.
