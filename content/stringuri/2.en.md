# Strings, bytes and runes — Practitioner

Building strings efficiently, working with `[]byte`, `strings` functions that avoid allocations, and the new iterators for lines and fields.

## `strings.Builder` for concatenation in a loop

Each `s += x` creates a new string and copies everything before it. In a loop, the cost grows quadratically. `strings.Builder` writes into a buffer that grows geometrically:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var b strings.Builder
	b.Grow(64) // optional: reserve space
	for i := range 5 {
		fmt.Fprintf(&b, "line %d\n", i)
	}
	b.WriteString("done")
	fmt.Println(b.String())
}
```

For an existing list, `strings.Join` does the same in a single allocation.

## `[]byte` and the `bytes` package

Data from files and the network usually comes as `[]byte`. The `bytes` package has almost the same functions as `strings`, so you can work without conversions:

```go
package main

import (
	"bytes"
	"fmt"
)

func main() {
	data := []byte("key=value")
	if i := bytes.IndexByte(data, '='); i >= 0 {
		fmt.Printf("%s -> %s\n", data[:i], data[i+1:])
	}

	var buf bytes.Buffer // implements io.Reader and io.Writer
	buf.WriteString("hello ")
	buf.Write([]byte("world"))
	fmt.Println(buf.String())
}
```

The conversions `string(b)` and `[]byte(s)` **copy** the data (with a few exceptions optimized by the compiler, see the Expert level).

## `strings.Cut`

Splits a string at the first occurrence of a separator. It replaces most `Index` + substring patterns:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	key, value, ok := strings.Cut("host=localhost", "=")
	fmt.Println(key, value, ok) // host localhost true

	if rest, ok := strings.CutPrefix("Bearer abc123", "Bearer "); ok {
		fmt.Println("token:", rest)
	}
}
```

## Iterators: `Lines`, `SplitSeq`, `FieldsSeq` (Go 1.24)

`strings.Split` allocates a slice with all the pieces. The variants returning **iterators** produce the pieces one at a time, without the intermediate slice:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "first\nsecond\nthird\n"
	for line := range strings.Lines(text) { // each line includes "\n"
		fmt.Printf("%q\n", line)
	}
	for field := range strings.SplitSeq("a,b,c", ",") {
		fmt.Print(field, " ")
	}
	fmt.Println()
}
```

## Working with characters: `unicode` and `utf8`

```go
package main

import (
	"fmt"
	"strings"
	"unicode"
	"unicode/utf8"
)

func main() {
	s := "Ana has 3 apples!"
	letters, digits := 0, 0
	for _, r := range s {
		switch {
		case unicode.IsLetter(r):
			letters++
		case unicode.IsDigit(r):
			digits++
		}
	}
	fmt.Println(letters, digits) // 12 1

	// the first character, decoded by hand
	r, size := utf8.DecodeRuneInString("ăsta")
	fmt.Printf("%c takes %d bytes\n", r, size)

	// character-by-character transformation
	fmt.Println(strings.Map(func(r rune) rune {
		if unicode.IsSpace(r) {
			return '_'
		}
		return r
	}, "a b c"))
}
```

## Safe truncation

Cutting a string at a number of **bytes** can split a character in two:

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func truncate(s string, n int) string {
	if utf8.RuneCountInString(s) <= n {
		return s
	}
	r := []rune(s)
	return string(r[:n]) + "…"
}

func main() {
	s := "Știință"
	fmt.Println(s[:3])                   // "Ș" + an invalid byte
	fmt.Println(utf8.ValidString(s[:3])) // false
	fmt.Println(truncate(s, 3))          // Ști…
}
```

## Formatting with `fmt`

| Verb | Example | Result |
|---|---|---|
| `%s` | `"go"` | `go` |
| `%q` | `"go\n"` | `"go\n"` |
| `%x` | `"go"` | `676f` |
| `%c` | `'ș'` | `ș` |
| `%U` | `'ș'` | `U+0219` |
| `%-8s` | `"go"` | `go      ` (left-aligned, width 8) |
| `%8.2f` | `3.14159` | `    3.14` |

## Case-insensitive comparison

`strings.EqualFold` compares without allocating. Avoid `strings.ToLower(a) == strings.ToLower(b)`, which creates two new strings.

## Normalization

Unicode lets the same character be written in several ways: `ș` can be a single code point (U+0219) or `s` + a combining comma (U+0326). They look identical, but `==` sees them as different. For robust comparisons, normalize text with `golang.org/x/text/unicode/norm` (for example the NFC form).

## Summary

- `strings.Builder` or `strings.Join` for repeated concatenation.
- The `bytes` package avoids needless conversions.
- `strings.Cut` for simple splits; `Lines` and `SplitSeq` without allocations.
- Cut strings at characters, not bytes.
- `EqualFold` for case-insensitive comparisons.
