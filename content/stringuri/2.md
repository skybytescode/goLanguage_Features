# Stringuri, bytes și runes — Practician

Construirea eficientă a stringurilor, lucrul cu `[]byte`, funcțiile din `strings` care evită alocări și iteratorii noi pentru linii și câmpuri.

## `strings.Builder` pentru concatenare în buclă

Fiecare `s += x` creează un string nou și copiază tot ce era înainte. Într-o buclă, costul crește pătratic. `strings.Builder` scrie într-un buffer care crește geometric:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	var b strings.Builder
	b.Grow(64) // opțional: rezervă spațiu
	for i := range 5 {
		fmt.Fprintf(&b, "linia %d\n", i)
	}
	b.WriteString("gata")
	fmt.Println(b.String())
}
```

Pentru o listă deja existentă, `strings.Join` face același lucru într-o singură alocare.

## `[]byte` și pachetul `bytes`

Datele care vin din fișiere și rețea sunt de obicei `[]byte`. Pachetul `bytes` are aproape aceleași funcții ca `strings`, deci poți lucra fără conversii:

```go
package main

import (
	"bytes"
	"fmt"
)

func main() {
	date := []byte("cheie=valoare")
	if i := bytes.IndexByte(date, '='); i >= 0 {
		fmt.Printf("%s -> %s\n", date[:i], date[i+1:])
	}

	var buf bytes.Buffer // implementează io.Reader și io.Writer
	buf.WriteString("salut ")
	buf.Write([]byte("lume"))
	fmt.Println(buf.String())
}
```

Conversiile `string(b)` și `[]byte(s)` **copiază** datele (cu câteva excepții optimizate de compilator, vezi nivelul Expert).

## `strings.Cut`

Împarte un string la prima apariție a unui separator. Înlocuiește majoritatea tiparelor cu `Index` + sub-stringuri:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	cheie, valoare, ok := strings.Cut("host=localhost", "=")
	fmt.Println(cheie, valoare, ok) // host localhost true

	if rest, ok := strings.CutPrefix("Bearer abc123", "Bearer "); ok {
		fmt.Println("token:", rest)
	}
}
```

## Iteratori: `Lines`, `SplitSeq`, `FieldsSeq` (Go 1.24)

`strings.Split` alocă un slice cu toate bucățile. Variantele care întorc **iteratori** produc bucățile pe rând, fără slice-ul intermediar:

```go
package main

import (
	"fmt"
	"strings"
)

func main() {
	text := "prima\na doua\na treia\n"
	for linie := range strings.Lines(text) { // fiecare linie include "\n"
		fmt.Printf("%q\n", linie)
	}
	for camp := range strings.SplitSeq("a,b,c", ",") {
		fmt.Print(camp, " ")
	}
	fmt.Println()
}
```

## Lucrul cu caractere: `unicode` și `utf8`

```go
package main

import (
	"fmt"
	"strings"
	"unicode"
	"unicode/utf8"
)

func main() {
	s := "Ana are 3 mere!"
	litere, cifre := 0, 0
	for _, r := range s {
		switch {
		case unicode.IsLetter(r):
			litere++
		case unicode.IsDigit(r):
			cifre++
		}
	}
	fmt.Println(litere, cifre) // 10 1

	// primul caracter, decodat manual
	r, dim := utf8.DecodeRuneInString("ăsta")
	fmt.Printf("%c ocupă %d octeți\n", r, dim)

	// transformare caracter cu caracter
	fmt.Println(strings.Map(func(r rune) rune {
		if unicode.IsSpace(r) {
			return '_'
		}
		return r
	}, "a b c"))
}
```

## Trunchierea sigură

Tăierea unui string la un număr de **octeți** poate rupe un caracter în două:

```go
package main

import (
	"fmt"
	"unicode/utf8"
)

func trunchiaza(s string, n int) string {
	if utf8.RuneCountInString(s) <= n {
		return s
	}
	r := []rune(s)
	return string(r[:n]) + "…"
}

func main() {
	s := "Știință"
	fmt.Println(s[:3])                   // "Ș" + un octet invalid
	fmt.Println(utf8.ValidString(s[:3])) // false
	fmt.Println(trunchiaza(s, 3))        // Ști…
}
```

## Formatare cu `fmt`

| Verb | Exemplu | Rezultat |
|---|---|---|
| `%s` | `"go"` | `go` |
| `%q` | `"go\n"` | `"go\n"` |
| `%x` | `"go"` | `676f` |
| `%c` | `'ș'` | `ș` |
| `%U` | `'ș'` | `U+0219` |
| `%-8s` | `"go"` | `go      ` (aliniat la stânga, lățime 8) |
| `%8.2f` | `3.14159` | `    3.14` |

## Comparații fără diferența de majuscule

`strings.EqualFold` compară fără să aloce. Evită `strings.ToLower(a) == strings.ToLower(b)`, care creează două stringuri noi.

## Normalizare

Unicode permite ca același caracter să fie scris în mai multe feluri: `ș` poate fi un singur cod (U+0219) sau `s` + virgula combinată (U+0326). Ele arată identic, dar `==` le vede diferite. Pentru comparații robuste, normalizează textul cu `golang.org/x/text/unicode/norm` (de exemplu forma NFC).

## Pe scurt

- `strings.Builder` sau `strings.Join` pentru concatenări repetate.
- Pachetul `bytes` evită conversiile inutile.
- `strings.Cut` pentru împărțiri simple; `Lines` și `SplitSeq` fără alocări.
- Taie stringurile la caractere, nu la octeți.
- `EqualFold` pentru comparații fără majuscule.
