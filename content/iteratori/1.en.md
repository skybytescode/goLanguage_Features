# Range and iterators — Fundamentals

`for ... range` is the standard way to walk any collection in Go. Since Go 1.22 it also works over numbers, and since Go 1.23 over **iterator functions**, which lets you make your own collections walkable with `range`.

## Recap: what `range` can walk

```go
package main

import "fmt"

func main() {
	for i, v := range []string{"a", "b"} { // slice: index, value
		fmt.Println(i, v)
	}
	for k, v := range map[string]int{"x": 1} { // map: key, value
		fmt.Println(k, v)
	}
	for i, r := range "hé" { // string: byte index, character
		fmt.Println(i, string(r))
	}
	for i := range 3 { // integer (Go 1.22): 0, 1, 2
		fmt.Println(i)
	}
	ch := make(chan int, 2)
	ch <- 10
	ch <- 20
	close(ch)
	for v := range ch { // channel: until it's closed
		fmt.Println(v)
	}
}
```

## Iterators from the standard library

Many functions in `slices`, `maps` and `strings` return **iterators**: values you can walk with `range`, without creating an intermediate slice.

```go
package main

import (
	"fmt"
	"maps"
	"slices"
)

func main() {
	names := []string{"Ana", "Ion", "Eva"}

	for i, n := range slices.Backward(names) { // from the end to the start
		fmt.Println(i, n)
	}

	ages := map[string]int{"Ana": 30, "Ion": 25}
	for _, k := range slices.Sorted(maps.Keys(ages)) { // sorted keys
		fmt.Println(k, ages[k])
	}
}
```

## Your first iterator

An iterator is a function that receives another function, usually called `yield`. The iterator calls `yield` for each value. If `yield` returns `false`, the loop has stopped (with `break`) and the iterator must stop too:

```go
package main

import "fmt"

// evenNumbers yields the even numbers from 0 up to max.
func evenNumbers(max int) func(yield func(int) bool) {
	return func(yield func(int) bool) {
		for i := 0; i <= max; i += 2 {
			if !yield(i) {
				return // the loop did a break
			}
		}
	}
}

func main() {
	for n := range evenNumbers(10) {
		if n > 6 {
			break
		}
		fmt.Println(n) // 0 2 4 6
	}
}
```

The body of the `for` loop effectively becomes the `yield` function.

## The `iter.Seq` and `iter.Seq2` types

The `iter` package names the two shapes of iterators:

- `iter.Seq[V]` — yields one value per step (like `for v := range`);
- `iter.Seq2[K, V]` — yields two values per step (like `for k, v := range`).

```go
package main

import (
	"fmt"
	"iter"
)

func Count(n int) iter.Seq[int] {
	return func(yield func(int) bool) {
		for i := 1; i <= n; i++ {
			if !yield(i) {
				return
			}
		}
	}
}

func Enumerate(words []string) iter.Seq2[int, string] {
	return func(yield func(int, string) bool) {
		for i, w := range words {
			if !yield(i+1, w) {
				return
			}
		}
	}
}

func main() {
	for n := range Count(3) {
		fmt.Print(n, " ")
	}
	fmt.Println()
	for nr, w := range Enumerate([]string{"one", "two"}) {
		fmt.Println(nr, w)
	}
}
```

## From an iterator to a slice

`slices.Collect` gathers every value of an iterator into a slice:

```go
package main

import (
	"fmt"
	"maps"
	"slices"
)

func main() {
	m := map[string]bool{"go": true, "rust": true}
	langs := slices.Collect(maps.Keys(m))
	slices.Sort(langs)
	fmt.Println(langs) // [go rust]
}
```

## Summary

- `range` works over slices, arrays, maps, strings, channels, integers and functions.
- An iterator is a function that calls `yield` for each value.
- When `yield` returns `false`, the iterator stops.
- `iter.Seq` and `iter.Seq2` are the standard iterator types.
- `slices.Collect` turns an iterator into a slice.
