# Arrays și slices — Fundamente

Go are două tipuri pentru secvențe de elemente: **array**-ul, cu lungime fixă, și **slice**-ul, cu lungime variabilă. În practică vei folosi aproape mereu slices.

## Array-uri

Lungimea face parte din tip: `[3]int` și `[4]int` sunt tipuri diferite.

```go
package main

import "fmt"

func main() {
	var a [3]int // [0 0 0]
	a[0] = 10
	b := [3]string{"a", "b", "c"}
	c := [...]int{1, 2, 3, 4} // compilatorul numără: [4]int

	fmt.Println(a, b, c, len(c))
}
```

## Slices

Un slice e o „fereastră” peste un array, cu lungime variabilă. Se scrie fără lungime în paranteze: `[]int`.

```go
package main

import "fmt"

func main() {
	numere := []int{1, 2, 3} // literal de slice
	numere = append(numere, 4, 5)
	fmt.Println(numere, len(numere)) // [1 2 3 4 5] 5

	var gol []int // nil, lungime 0: append funcționează direct
	gol = append(gol, 42)
	fmt.Println(gol)
}
```

**Important:** `append` întoarce slice-ul nou. Trebuie mereu să atribui rezultatul: `s = append(s, x)`.

## `make`: slice cu lungime și capacitate

`make([]T, lungime, capacitate)` creează un slice cu elemente zero. Capacitatea e spațiul deja rezervat:

```go
package main

import "fmt"

func main() {
	s := make([]int, 3) // [0 0 0], len 3, cap 3
	fmt.Println(s, len(s), cap(s))

	t := make([]int, 0, 10) // gol, dar cu loc pentru 10 elemente
	for i := range 5 {
		t = append(t, i*i)
	}
	fmt.Println(t, len(t), cap(t)) // [0 1 4 9 16] 5 10
}
```

## Sub-slices

`s[a:b]` ia elementele de la indexul `a` până la `b`, **fără** `b`. Oricare capăt poate lipsi:

```go
package main

import "fmt"

func main() {
	s := []string{"a", "b", "c", "d", "e"}
	fmt.Println(s[1:3]) // [b c]
	fmt.Println(s[:2])  // [a b]
	fmt.Println(s[3:])  // [d e]
	fmt.Println(s[:])   // tot
}
```

## Parcurgerea

```go
package main

import "fmt"

func main() {
	note := []int{9, 7, 10}
	suma := 0
	for _, n := range note {
		suma += n
	}
	fmt.Printf("media: %.2f\n", float64(suma)/float64(len(note)))
}
```

## `copy`

`copy(dst, src)` copiază elemente și întoarce câte a copiat (minimul dintre cele două lungimi):

```go
package main

import "fmt"

func main() {
	src := []int{1, 2, 3}
	dst := make([]int, 2)
	n := copy(dst, src)
	fmt.Println(dst, n) // [1 2] 2
}
```

## Pachetul `slices`

Din Go 1.21, pachetul `slices` are funcțiile pe care le-ai scrie altfel de mână:

```go
package main

import (
	"fmt"
	"slices"
)

func main() {
	s := []int{5, 2, 8, 1}
	fmt.Println(slices.Contains(s, 8)) // true
	fmt.Println(slices.Index(s, 2))    // 1
	fmt.Println(slices.Max(s))         // 8

	slices.Sort(s)
	fmt.Println(s) // [1 2 5 8]
}
```

## Slices în mai multe dimensiuni

```go
package main

import "fmt"

func main() {
	tabla := [][]string{
		{"X", "O", "X"},
		{" ", "X", "O"},
		{"O", " ", "X"},
	}
	for _, rand := range tabla {
		fmt.Println(rand)
	}
}
```

## Pe scurt

- Array: lungime fixă, parte din tip. Slice: lungime variabilă.
- `s = append(s, x)`: atribuie mereu rezultatul.
- `make([]T, len, cap)` rezervă spațiu dinainte.
- `s[a:b]` include `a`, exclude `b`.
- Pachetul `slices` are sortare, căutare și multe altele.
