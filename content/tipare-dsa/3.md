# Tipare DSA — Avansat

Arbori și grafuri. Trei dintre tiparele de aici — parcurgerile de arbori, DFS și BFS — sunt în lista originală; **Union-Find** și **Topological Sort** au fost sugerate în comentarii și sunt cele două unelte pentru grafuri pe care listele de interviu le omit cel mai des. Punctul comun: vizitezi fiecare nod și fiecare muchie de un număr limitat de ori, așa că majoritatea soluțiilor sunt O(V + E).

## Cum reprezinți un graf în Go

| Reprezentare | Tip Go | Când |
|---|---|---|
| Listă de adiacență | `[][]int` (noduri `0..n-1`) | aproape mereu; memorie O(V + E) |
| Listă de adiacență cu chei | `map[string][]string` | noduri cu nume (cuvinte, cursuri) |
| Grilă implicită | `[][]byte` + array de direcții | insule, labirinturi, portocale |
| Listă de muchii | `[][2]int` | intrarea pentru Union-Find și Kruskal |
| Matrice de adiacență | `[][]bool` | grafuri mici și dense; memorie O(V²) |

**La ce folosește fiecare ordine:**

- **preorder** — copierea sau serializarea unui arbore; rădăcina vine prima, deci îl poți reconstrui;
- **inorder** — un BST în ordine sortată; „al k-lea cel mai mic element”; validarea unui BST;
- **postorder** — tot ce are nevoie întâi de răspunsul copiilor: înălțimea, diametrul, ștergerea unui arbore;
- **pe niveluri** — „pe nivel”, „vederea din dreapta”, adâncimea minimă.

```go
package main

import (
	"fmt"
	"iter"
)

type TreeNode struct {
	Val         int
	Left, Right *TreeNode
}

// inorder, recursiv: forma cea mai simplă.
func inorder(n *TreeNode, visit func(int)) {
	if n == nil {
		return
	}
	inorder(n.Left, visit)
	visit(n.Val)
	inorder(n.Right, visit)
}

// inorderIterative (LeetCode 94) cu o stivă explicită: mergi la stânga cât
// de mult poți, procesezi, apoi treci în subarborele drept.
func inorderIterative(root *TreeNode) []int {
	var res []int
	var stack []*TreeNode
	for n := root; n != nil || len(stack) > 0; {
		for ; n != nil; n = n.Left {
			stack = append(stack, n)
		}
		n = stack[len(stack)-1]
		stack = stack[:len(stack)-1]
		res = append(res, n.Val)
		n = n.Right
	}
	return res
}

// levelOrder (LeetCode 102): BFS; lungimea cozii la începutul unui nivel
// este exact numărul de noduri de pe acel nivel.
func levelOrder(root *TreeNode) [][]int {
	if root == nil {
		return nil
	}
	var res [][]int
	queue := []*TreeNode{root}
	for len(queue) > 0 {
		level := make([]int, 0, len(queue))
		for range len(queue) {
			n := queue[0]
			queue = queue[1:]
			level = append(level, n.Val)
			if n.Left != nil {
				queue = append(queue, n.Left)
			}
			if n.Right != nil {
				queue = append(queue, n.Right)
			}
		}
		res = append(res, level)
	}
	return res
}

// buildTree (LeetCode 105): preorder dă rădăcina, poziția ei în inorder
// separă subarborele stâng de cel drept.
func buildTree(preorder, inorder []int) *TreeNode {
	pos := make(map[int]int, len(inorder)) // valoare → index în inorder
	for i, v := range inorder {
		pos[v] = i
	}
	next := 0 // următoarea rădăcină din preorder
	var build func(lo, hi int) *TreeNode
	build = func(lo, hi int) *TreeNode { // subarborele este inorder[lo:hi]
		if lo >= hi {
			return nil
		}
		root := &TreeNode{Val: preorder[next]}
		next++
		mid := pos[root.Val]
		root.Left = build(lo, mid)
		root.Right = build(mid+1, hi)
		return root
	}
	return build(0, len(inorder))
}

// All este un iterator inorder (Go 1.23+): poate fi folosit cu range și se
// oprește imediat ce bucla face break.
func (n *TreeNode) All() iter.Seq[int] {
	return func(yield func(int) bool) {
		var walk func(*TreeNode) bool
		walk = func(n *TreeNode) bool {
			return n == nil || walk(n.Left) && yield(n.Val) && walk(n.Right)
		}
		walk(n)
	}
}

func main() {
	root := buildTree([]int{4, 2, 1, 3, 6, 5, 7}, []int{1, 2, 3, 4, 5, 6, 7})

	inorder(root, func(v int) { fmt.Print(v, " ") })
	fmt.Println()                       // 1 2 3 4 5 6 7
	fmt.Println(inorderIterative(root)) // [1 2 3 4 5 6 7]
	fmt.Println(levelOrder(root))       // [[4] [2 6] [1 3 5 7]]

	for v := range root.All() { // al 3-lea cel mai mic element
		if v == 3 {
			fmt.Println("găsit", v) // găsit 3
			break
		}
	}
}
```

> `queue = queue[1:]` este cea mai simplă coadă în Go. Slice-ul „înaintează” peste array-ul de bază; `append` realocă din când în când, iar partea consumată poate fi colectată. Pentru o coadă care trăiește mult, cu multe operații, un ring buffer evită copierile.

**Complexitate:** timp O(n); memorie O(h) pentru DFS (h = înălțimea), O(w) pentru BFS (w = lățimea maximă). **Exersează:** [102. Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/) · [94. Binary Tree Inorder Traversal](https://leetcode.com/problems/binary-tree-inorder-traversal/) · [105. Construct Binary Tree from Preorder and Inorder Traversal](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)

```go
package main

import "fmt"

// numIslands (LeetCode 200). Marchează celulele vizitate schimbându-le în '0';
// dacă intrarea trebuie să rămână intactă, folosește un visited [][]bool separat.
func numIslands(grid [][]byte) int {
	rows, cols := len(grid), len(grid[0])
	var sink func(r, c int)
	sink = func(r, c int) {
		if r < 0 || r >= rows || c < 0 || c >= cols || grid[r][c] != '1' {
			return
		}
		grid[r][c] = '0'
		sink(r+1, c)
		sink(r-1, c)
		sink(r, c+1)
		sink(r, c-1)
	}
	count := 0
	for r := range rows {
		for c := range cols {
			if grid[r][c] == '1' {
				count++
				sink(r, c)
			}
		}
	}
	return count
}

type Node struct {
	Val       int
	Neighbors []*Node
}

// cloneGraph (LeetCode 133). Map-ul este atât „vizitat”, cât și „vechi → copie”;
// fără el, un ciclu ar face recursivitatea infinită.
func cloneGraph(n *Node) *Node {
	copies := map[*Node]*Node{}
	var clone func(*Node) *Node
	clone = func(n *Node) *Node {
		if n == nil {
			return nil
		}
		if c, ok := copies[n]; ok {
			return c
		}
		c := &Node{Val: n.Val}
		copies[n] = c // înaintea vecinilor: ei pot arăta înapoi spre n
		for _, nb := range n.Neighbors {
			c.Neighbors = append(c.Neighbors, clone(nb))
		}
		return c
	}
	return clone(n)
}

type TreeNode struct {
	Val         int
	Left, Right *TreeNode
}

// diameterOfBinaryTree (LeetCode 543): DFS în postorder. Funcția întoarce
// înălțimea, iar pe drum actualizează cel mai lung drum prin fiecare nod
// (înălțimea stângă + înălțimea dreaptă).
func diameterOfBinaryTree(root *TreeNode) int {
	best := 0
	var height func(*TreeNode) int
	height = func(n *TreeNode) int {
		if n == nil {
			return 0
		}
		l, r := height(n.Left), height(n.Right)
		best = max(best, l+r)
		return 1 + max(l, r)
	}
	height(root)
	return best
}

func main() {
	grid := [][]byte{
		[]byte("11000"),
		[]byte("11000"),
		[]byte("00100"),
		[]byte("00011"),
	}
	fmt.Println(numIslands(grid)) // 3

	// pătratul 1-2-3-4-1
	n1, n2, n3, n4 := &Node{Val: 1}, &Node{Val: 2}, &Node{Val: 3}, &Node{Val: 4}
	n1.Neighbors = []*Node{n2, n4}
	n2.Neighbors = []*Node{n1, n3}
	n3.Neighbors = []*Node{n2, n4}
	n4.Neighbors = []*Node{n1, n3}
	c := cloneGraph(n1)
	fmt.Println(c != n1, c.Val, c.Neighbors[0].Val, c.Neighbors[1].Val) // true 1 2 4
	fmt.Println(c.Neighbors[0].Neighbors[0] == c)                       // true: 2 arată înapoi spre copia lui 1

	root := &TreeNode{1, &TreeNode{2, &TreeNode{Val: 4}, &TreeNode{Val: 5}}, &TreeNode{Val: 3}}
	fmt.Println(diameterOfBinaryTree(root)) // 3 (4 → 2 → 1 → 3)
}
```

> Recursivitatea adâncă e mai puțin riscantă în Go decât în Java sau Python: stivele goroutine-urilor pornesc mici și **cresc** după nevoie, până la 1 GB implicit pe sistemele pe 64 de biți. Un DFS adânc de un milion de niveluri funcționează, dar consumă multă memorie; o stivă explicită (`[]int`) îl ține sub control.

Pentru detectarea ciclurilor într-un graf **orientat**, un boolean `visited` nu ajunge: ai nevoie de trei stări — nevizitat, *în curs* (pe drumul curent) și terminat. Dacă găsești un vecin „în curs”, ai un ciclu. Sortarea topologică (secțiunea 16) face același lucru altfel.

**Complexitate:** O(V + E); pentru o grilă, O(rows·cols). **Exersează:** [200. Number of Islands](https://leetcode.com/problems/number-of-islands/) · [133. Clone Graph](https://leetcode.com/problems/clone-graph/) · [543. Diameter of Binary Tree](https://leetcode.com/problems/diameter-of-binary-tree/)

## 14. Breadth-First Search (căutare în lățime)

*Explorezi nivel cu nivel.* O coadă ține „frontul de undă”: întâi toate nodurile la distanța 1, apoi toate cele la distanța 2 și așa mai departe. **Semnale:** „numărul minim de pași / mutări / transformări”, „drumul cel mai scurt” cu costuri egale, răspândire în valuri (foc, infecție), „distanța până la cel mai apropiat…”, orice „pe niveluri”.

```go
package main

import "fmt"

// orangesRotting (LeetCode 994): 0 gol, 1 proaspătă, 2 stricată.
func orangesRotting(grid [][]int) int {
	type cell struct{ r, c int }
	var queue []cell
	fresh := 0
	for r, row := range grid {
		for c, v := range row {
			switch v {
			case 2:
				queue = append(queue, cell{r, c}) // toate sursele deodată
			case 1:
				fresh++
			}
		}
	}
	dirs := [4]cell{{-1, 0}, {1, 0}, {0, -1}, {0, 1}}
	minutes := 0
	for len(queue) > 0 && fresh > 0 {
		minutes++
		for range len(queue) { // exact un nivel
			cur := queue[0]
			queue = queue[1:]
			for _, d := range dirs {
				r, c := cur.r+d.r, cur.c+d.c
				if r >= 0 && r < len(grid) && c >= 0 && c < len(grid[0]) && grid[r][c] == 1 {
					grid[r][c] = 2 // marchezi când o PUI în coadă, nu când o scoți
					fresh--
					queue = append(queue, cell{r, c})
				}
			}
		}
	}
	if fresh > 0 {
		return -1 // unele portocale nu pot fi atinse niciodată
	}
	return minutes
}

// ladderLength (LeetCode 127): graful este implicit; două cuvinte sunt
// vecine dacă diferă printr-o literă. Generăm vecinii în loc să comparăm
// fiecare pereche de cuvinte.
func ladderLength(begin, end string, words []string) int {
	dict := map[string]bool{}
	for _, w := range words {
		dict[w] = true
	}
	if !dict[end] {
		return 0
	}
	queue := []string{begin}
	delete(dict, begin)
	for steps := 1; len(queue) > 0; steps++ {
		for range len(queue) {
			w := []byte(queue[0])
			queue = queue[1:]
			if string(w) == end {
				return steps
			}
			for i := range w {
				orig := w[i]
				for ch := byte('a'); ch <= 'z'; ch++ {
					w[i] = ch
					if s := string(w); dict[s] {
						delete(dict, s) // vizitat
						queue = append(queue, s)
					}
				}
				w[i] = orig
			}
		}
	}
	return 0
}

func main() {
	fmt.Println(orangesRotting([][]int{{2, 1, 1}, {1, 1, 0}, {0, 1, 1}})) // 4
	fmt.Println(orangesRotting([][]int{{2, 1, 1}, {0, 1, 1}, {1, 0, 1}})) // -1

	words := []string{"hot", "dot", "dog", "lot", "log", "cog"}
	fmt.Println(ladderLength("hit", "cog", words)) // 5: hit → hot → dot → dog → cog
}
```

> Marchează un nod ca vizitat când îl **pui în coadă**, nu când îl scoți. Altfel același nod poate fi adăugat de multe ori de vecini diferiți, iar pe o grilă coada poate crește exponențial.

*01 Matrix* (LeetCode 542) este aceeași idee ca la portocale: pune **toate** zerourile în coadă la început, iar BFS-ul dă fiecărei celule distanța până la cel mai apropiat zero. Cu muchii de costuri diferite, BFS nu mai ajunge: ai nevoie de Dijkstra (un BFS cu un heap în loc de coadă).

**Complexitate:** O(V + E). **Exersează:** [127. Word Ladder](https://leetcode.com/problems/word-ladder/) · [994. Rotting Oranges](https://leetcode.com/problems/rotting-oranges/) · [542. 01 Matrix](https://leetcode.com/problems/01-matrix/)

## 15. Union-Find (Disjoint Set Union, mulțimi disjuncte)

*„Sunt acestea două în același grup?” în aproape O(1).* Fiecare grup este un arbore, iar rădăcina este reprezentantul grupului. `Find` urcă până la rădăcină; `Union` atașează o rădăcină sub cealaltă. Două optimizări fac arborii aproape plați: **union by size** (arborele mic merge sub cel mare) și **path compression** (pe drumul în sus, nodurile sunt mutate mai aproape de rădăcină).

**Semnale:** „componente conexe” când muchiile tot **sosesc** (nu poți face ușor asta cu DFS), „muchia redundantă care închide un ciclu”, unirea conturilor/grupurilor după un element comun, arborele parțial de cost minim al lui Kruskal.

```go
package main

import "fmt"

type UnionFind struct {
	parent, size []int
	count        int // numărul de grupuri
}

func NewUnionFind(n int) *UnionFind {
	uf := &UnionFind{parent: make([]int, n), size: make([]int, n), count: n}
	for i := range n {
		uf.parent[i] = i
		uf.size[i] = 1
	}
	return uf
}

// Find întoarce rădăcina, cu „path halving”: fiecare nod de pe drum este
// mutat sub bunicul lui. Iterativ, deci fără recursivitate adâncă.
func (uf *UnionFind) Find(x int) int {
	for uf.parent[x] != x {
		uf.parent[x] = uf.parent[uf.parent[x]]
		x = uf.parent[x]
	}
	return x
}

// Union unește grupurile lui a și b. Întoarce false dacă erau deja
// în același grup: muchia (a, b) închide un ciclu.
func (uf *UnionFind) Union(a, b int) bool {
	ra, rb := uf.Find(a), uf.Find(b)
	if ra == rb {
		return false
	}
	if uf.size[ra] < uf.size[rb] {
		ra, rb = rb, ra
	}
	uf.parent[rb] = ra // arborele mai mic merge sub cel mai mare
	uf.size[ra] += uf.size[rb]
	uf.count--
	return true
}

// findCircleNum (LeetCode 547): numărul de provincii dintr-o matrice de adiacență.
func findCircleNum(isConnected [][]int) int {
	uf := NewUnionFind(len(isConnected))
	for i := range isConnected {
		for j := i + 1; j < len(isConnected); j++ {
			if isConnected[i][j] == 1 {
				uf.Union(i, j)
			}
		}
	}
	return uf.count
}

// findRedundantConnection (LeetCode 684): prima muchie care unește două
// noduri deja conectate. Nodurile sunt numerotate de la 1.
func findRedundantConnection(edges [][2]int) [2]int {
	uf := NewUnionFind(len(edges) + 1)
	for _, e := range edges {
		if !uf.Union(e[0], e[1]) {
			return e
		}
	}
	return [2]int{}
}

func main() {
	uf := NewUnionFind(6)
	uf.Union(0, 1)
	uf.Union(0, 2)
	uf.Union(3, 4)
	fmt.Println(uf.count, uf.Find(2) == uf.Find(4)) // 3 false
	uf.Union(2, 4)
	fmt.Println(uf.count, uf.Find(2) == uf.Find(4)) // 2 true

	fmt.Println(findCircleNum([][]int{{1, 1, 0}, {1, 1, 0}, {0, 0, 1}}))   // 2
	fmt.Println(findRedundantConnection([][2]int{{1, 2}, {1, 3}, {2, 3}})) // [2 3]
}
```

Cu ambele optimizări, fiecare operație costă O(α(n)), unde α este inversa funcției Ackermann — sub 5 pentru orice `n` care încape în memorie. În practică: constant.

**Complexitate:** ≈ O(1) pe operație, memorie O(n). **Exersează:** [547. Number of Provinces](https://leetcode.com/problems/number-of-provinces/) · [684. Redundant Connection](https://leetcode.com/problems/redundant-connection/) · [721. Accounts Merge](https://leetcode.com/problems/accounts-merge/)

**Semnale:** cerințe preliminare, dependențe, „ordinea de build”, „pot fi terminate toate cursurile?”, o rețetă care are nevoie de alte rețete, ordinea sarcinilor într-un pipeline.

Chiar toolchain-ul Go o folosește: pachetele sunt compilate într-o ordine topologică a grafului de importuri, iar `import cycle not allowed` este exact cazul în care acea ordine nu există.

```go
package main

import "fmt"

// findOrder (LeetCode 210): numCourses cursuri, prereq[i] = {curs, necesită}.
// Întoarce o ordine sau false dacă există un ciclu (LeetCode 207).
func findOrder(numCourses int, prereq [][2]int) ([]int, bool) {
	adj := make([][]int, numCourses)
	indeg := make([]int, numCourses)
	for _, p := range prereq {
		course, needs := p[0], p[1]
		adj[needs] = append(adj[needs], course) // needs → course
		indeg[course]++
	}
	var queue []int
	for c, d := range indeg {
		if d == 0 {
			queue = append(queue, c)
		}
	}
	order := make([]int, 0, numCourses)
	for len(queue) > 0 {
		c := queue[0]
		queue = queue[1:]
		order = append(order, c)
		for _, next := range adj[c] {
			indeg[next]--
			if indeg[next] == 0 { // toate cerințele lui sunt îndeplinite
				queue = append(queue, next)
			}
		}
	}
	// dacă există un ciclu, nodurile lui nu ajung niciodată la gradul de intrare 0
	return order, len(order) == numCourses
}

func main() {
	// 0=A, 1=B, 2=C, 3=D, 4=E ca în diagramă
	edges := [][2]int{{1, 0}, {2, 0}, {3, 1}, {3, 2}, {4, 3}}
	fmt.Println(findOrder(5, edges)) // [0 1 2 3 4] true

	fmt.Println(findOrder(2, [][2]int{{0, 1}, {1, 0}})) // [] false: un ciclu
}
```

Alternativa cu DFS: rulezi un DFS cu trei culori (secțiunea 13) și adaugi fiecare nod într-o listă **după** ce toți descendenții lui sunt terminați (postorder); lista inversată este o ordine topologică. Varianta lui Kahn are un avantaj: îți dă în mod natural „nivelurile” — ce se poate face în paralel la fiecare pas.

Course Schedule II](https://leetcode.com/problems/course-schedule-ii/) · [2115. Find All Possible Recipes from Given Supplies](https://leetcode.com/problems/find-all-possible-recipes-from-given-supplies/)

## Rezumat

- Parcurgerile diferă doar prin momentul în care e procesat nodul; postorder e pentru „răspunsul de la copii”, parcurgerea pe niveluri e BFS.
- DFS: regiuni conexe, drumuri, clonare, cicluri; recursivitatea e ieftină în Go, dar nu e gratuită.
- BFS: drumul cel mai scurt în pași; marchezi când pui în coadă; mai multe surse pot porni în același timp.
- Union-Find: grupuri care se unesc în timp, cu union by size și path compression.
- Sortarea topologică: dependențe într-un DAG; algoritmul lui Kahn detectează și ciclurile.
